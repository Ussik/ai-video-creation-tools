# Findings

- 当前每项目一个图，canvas_nodes/edges 的主键是 project_id 与 id，前端保存队列和本地草稿按项目隔离。
- API 已限制每图 500 节点/1000 连线，使用内容签名乐观并发；需保留原验证和幂等重试。
- 外部素材加入画布使用旧项目级接口；需要改为最近使用的画布。
- 拖动已有最终一次保存机制，多个画布应保留这个行为。
- 节点 ID 继续在项目内唯一，明确图归属后所有 API 校验同图端点；移动更新归属，保留 ID 与固定参考快照，不复制项目资源。
- 活跃图切换通过卸载独立 React FlowProvider，保留轻量会话中的选择/撤销，本机草稿和视角分别隔离。原项目默认图使用旧本机 key，避免旧草稿丢失。
- 页面实际验证多画布菜单的位置与示例一致，新增空白图只有 0 个挂载节点，切回恢复选择和撤销；移动节点后仅目标图显示该节点，删除后最后一张禁删。
