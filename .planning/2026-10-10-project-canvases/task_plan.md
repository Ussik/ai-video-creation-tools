# 项目内多画布

## Goal
实现项目内新增、重命名、切换和删除画布，旧图迁入默认画布，独立保存图、视角、选择和撤销；共享项目资源，仅挂载当前画布。

## Phases
- [x] 核对存储、保存队列、导入与删除链路
- [x] 数据迁移及隔离的画布 API
- [x] 顶部画布菜单、独立编辑会话及跨画布移动
- [x] 回归测试、构建、页面验证与文档

## Constraints
- 保留已有未提交改动，不提交或推送。
- 删除画布仅删除节点和连线，不删除镜头、素材、设定或生成任务。
- 兼容原 /projects/:id/canvas 接口并固定指向默认画布。
- 切换保存失败不丢草稿；并发版本校验独立于其他画布。
- 不调用真实生成模型；不覆盖其他任务的活动计划指针。
