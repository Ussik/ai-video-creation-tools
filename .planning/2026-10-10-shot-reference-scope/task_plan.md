# 分镜图片与视频参考范围

## Goal
按每镜开镜图片与视频全程分别保存参考用途，统一提示词、参考图片和缺图检查，并纠正《言灵》首场已有五镜的全场继承。

## Phases
- [x] 增加可持久化的引用用途与共享筛选逻辑
- [x] 接入参考整理、镜头引用编辑及前后端生成链
- [x] 修正单幅分镜的设定板视图说明污染
- [x] 针对性测试、前后端构建及已有项目数据核对

## Constraints
- 保留工作区现有未提交改动；不提交、不推送。
- 不调用真实生成模型。
- 图片与视频共用对象版本及参考快照，但分别选择出镜用途。
- 历史缺少用途字段的客户端兼容为 both；新整理流程必须明确每镜用途。
- 项目数据修正先保存可恢复快照，再事务写入并复核。
