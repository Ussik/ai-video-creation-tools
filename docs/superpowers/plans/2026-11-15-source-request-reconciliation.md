# 原稿分析请求状态与本地恢复实施计划

日期：2026-11-15。前置：质量语义增强已交付 main、构建通过、15 张业务表指纹保持一致。本计划为用户随后明确授权的下一阶段，禁止新增付费模型请求、清理原记录、提交或推送。

## 目标

修复本地准入拒绝被误记成未知请求，以及空 blockers 恢复弹窗只刷新后关闭的空转。保留派发前 intent 的崩溃保护，通过请求台账、完整回答、可信本地准入结果及当前检查点身份决定下一步；无台账本身不等于确定未发送。

## 实施顺序

- [x] 以真实只读快照离线复现：旧 prepared 许可、独立复核新问题、残留 initial_started 与空 blockers。
- [x] 复核产生新问题时结束旧轮，保留结果并建立明确待用量确认的下一轮状态，不自动借用旧许可。
- [x] 明确准备发送、可信未发送、可能已发送、已有完整回答，可信准入拒绝释放精确 intent；真实断连与已受理预算中断仍受保护。
- [x] GET 提供只读事实和明确动作；正式本地恢复 POST 使用版本、并发和幂等保护并记录审计，不删旧请求或许可。
- [x] 恢复弹窗按真实动作显示：本地复用、纠正未发送状态、未知请求核对或矛盾阻断，不再空刷新后关闭。
- [x] 离线验证双击、重启、迟到回答、完整回答复用、真实未知不可清及旧许可隔离；验证实际按钮路径。
- [x] 空闲并检查漂移后应用 main，构建/读回，记录业务状态变化是否仅为用户明确执行的正式本地恢复操作。

## 所有权

- 轮次与授权：质量流程代理负责 analysis / quality / ordinary dispatch；共享分析类型只由该代理编辑。
- 准入结果：修补恢复代理负责 model-output / source-model-recovery 与局部新增模块。
- 恢复事实、正式操作及界面：状态代理负责 recovery admission / routes / checkpoints 和恢复弹窗。
- 主控：真实快照聚合回放、跨组件边界、main 交付与实际页面验收。

任何模型内容都不作为恢复权限；任何状态迁移均不得手工标记分析成功，也不能重做原稿、目录或已有模型成果。
