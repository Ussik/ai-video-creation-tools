# 独立分镜工作区设计

## 用户目标

从剧本规划分镜后可以先保存、继续修改，再按需加入画布。现有分镜管理需重新组织为完整工作区。沿用项目名菜单中的「分镜管理」入口，剧本提供「规划分镜」入口。

## 调研依据

2026-11-03 调研公开产品介绍与公开只读样例，未进行完整的登录后竞品使用或写入操作：

- [StudioBinder 产品介绍](https://www.studiobinder.com/shot-list-software/)：场次关联、镜头表格、镜头细节、分组、顺序与制作进度；支持镜头表与故事板视图。
- [StudioBinder 公开只读样例](https://app.studiobinder.com/shared/66ee07a4cb549cdd5a4c7abd)：实际查看场次/列表侧栏与镜头表，表格呈现 STATUS、IMAGE、SHOT、DESCRIPTION；缩略图、镜号和描述支持逐行扫描，并以细分隔线区分行。
- [Boords 产品介绍](https://boords.com/shot-list-software)：分镜画面与镜头列表保持关联，镜头细节/备注在同一工作区编辑，前期方案确认后交接制作。

此次采用按场次组织、便于横向扫描的镜头列表、独立详情编辑、清楚的保存与制作交接。延续本项目 Mantine、Lucide 和主题，不引入协作审批、实拍器材或排期功能。

## 页面结构

- 全屏分镜工作区：沿用现有分镜管理入口，剧本中的「规划分镜」也进入此处并带入场次范围；返回画布、项目名、方案选择、规划分镜；保留回收站与刷新。
- 场次导航：全部场次、各场镜头数与总时长；方案和场次选择有明确当前状态。
- 镜头表：真实画面缩略图或中性占位、镜号、画面标题/描述、时长、制作状态和画布引用；批量选择后展示加入画布操作。
- 详情：镜头内容、生成提示词、起止状态/接镜分组；显式保存；窄屏改为列表和详情逐级导航。
- 状态只使用已有事实：待制作、已有素材、已选片、未加入画布，不推测运行中的任务。

## 行为边界

- 独立规划保存只写分镜方案、镜头及规划来源，不调用参考设定模型、不创建画布/节点、不生成图片或视频素材；保存后回管理并选中新方案。
- 首次规划沿用默认方案；已有分镜可沿用更新或重新设计独立新方案，旧方案及素材保留。
- 新方案尚未加入画布与已删除旧画布通过 canvas_pending 显式区分；原画布已删除时需重新设计新方案，不静默恢复。
- 后续进入制作时再整理参考设定并创建/复用画布；旧加入画布流程兼容。单个 pending 方案交接明确提示创建其画布，混合 pending 方案需分批处理。
- 历史 pending 方案通过新鲜管理快照验证后可以准备制作，检查/整理/提交均绑定所选 design_id，并校验来源指纹；不能误用当前新方案的镜头或参考绑定。
- 保留现有编辑、同方案同场次排序、复制、回收、恢复、批量导入、冲突与离开确认。
- 不提交、不推送；保留当前所有未提交编辑。浏览器写入验收使用隔离数据，不更改用户现有剧本、分镜或模型设置。
