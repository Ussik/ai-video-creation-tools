# 场次估时校验与重新估时

目标：阻止剧本估时与正文明显矛盾的场次未经核对进入分镜，并允许对历史错误估时重新规划。

- [x] 剧本复核包含逐场时长与总计，检查对白、旁白、动作、停顿和明确时长要求；保留逐字证据与安全修订。
- [x] 区分场次与单镜时长：场次允许 1–600 秒，单镜仍为 1–30 秒；同步场次读写及编辑限制。
- [x] 正式分镜新增显式重新估时模式；默认沿用原时长，指定总时长仍为明确约束。
- [x] 重新估时模式绑定预览签名、复查和确认保存；规划阶段不改正式场次。
- [x] 验证短无声场次、长对白错误估时、时长修订、缓存失效、明确时长保护、保存/重放和历史兼容。

不采用统一字速或固定镜数推断，不自动改用户已保存的剧本、时长或模型配置。完成后运行相关测试、构建和独立代码复核；真实模型质量单独说明。

实现补充：原生定向修补读取 `scene:N:duration` 时同步提供同场完整结构字段；只读合计和目标不可成为补丁来源。旧场次直转及缺省镜头入口在写入前要求超过 30 秒的场次先规划分镜。

验证：剧本审读/修补与分镜规划 8 个后端测试文件合计 214 项通过；备用修补路径补齐后，3 个修补文件的 54 项测试复跑通过。分镜规划前端 38 项、剧本生成前端 17 项通过。完整构建及独立代码复核通过。

扩大兼容回归：`script.test.ts`、`script-document-tools.test.ts`、`script-canvas-preparation.test.ts` 共 134 项，131 项通过，`script.test.ts` 仍有 3 项非时长专项断言失败：阶段调用计数期望 6/3 次，实际 9/4 次；旧分镜用例期望裸视频提示词，实际追加了结构化声音执行约束。新增的场次 600 秒读写、超限拒绝及旧入口保护用例通过。没有通过修改无关产品行为来满足这些断言。

未修改正式数据库，未发起真实模型请求，因此模型实际估时质量与间歇性上游失败仍未经实测。
