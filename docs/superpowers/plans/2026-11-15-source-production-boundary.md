# 上传原稿不做分析审核：最终产品边界

日期：2026-11-15。最新用户纠正优先于此前的“可选审稿”和“上传后准备资料”方案。

用户原话：**“我上传的原稿剧本，不需要程序和模型接口做任何的分析审核处理！”**

1. 上传只进行必要技术读取、解码或文字提取、大小和格式检查、保存与展示。上传不创建模型请求、语义目录、人物表、事件、时间线、全剧理解、设定或问题清单，不启动后台分析、审核、修补或复核。
2. 默认父页面不自动读取制作目录或进行原稿解释。用户主动选择“选择本次制作范围”后，才在此明确任务中读取原文及技术位置，直接沿用分场正文。梗概/小说需用户主动选择目标集改编，不能伪造正文。
3. 聊天或明确创作任务直接读取原文。不注入旧语义分析包，不因其缺失或失败补分析，不把原稿作为独立准确性核对或审稿循环的对象。
4. 默认界面移除原稿分析、继续分析、反馈复核及计费恢复操作和自动轮询；原稿预览仅显示文本。历史处理信息只读保留，不评价当前原稿，不暗示必须修复或通过。
5. 旧failed/paused/issues、开放结局和未知事项均不是聊天、创作、分镜、视频制作的全局门禁。只检查当前任务必要技术输入。
6. 新生成成果的结构、合法引用、版本并发、执行参数和正式保存确认仍保留。原稿只读；原回答、有效成果、未知请求、预算及旧授权保留，不能伪造通过、宣称远端取消或自动重发。
7. 独立制作任务使用精确来源与任务身份。原文局部导入幂等，复用已保存场次，不覆盖人工编辑。新单集改编最多一次格式纠正，断连停止；更换提示或模型不能绕过本集未知请求。
8. 只在离线副本与模拟模型中验收，不新增付费验证授权，不调用图像/视频服务。不清库、不清Langfuse、不commit/push。交付主工作区main，保留原有全部未提交改动。
