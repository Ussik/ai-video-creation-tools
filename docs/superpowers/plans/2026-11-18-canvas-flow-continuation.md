# 分镜到画布流程补齐

直接修改主仓库 main，保留既有改动和数据，不提交或推送。仅使用隔离数据库与模拟模型验证。

- [x] 两个入口：新完成的完整参考结果自动保存并加入画布；恢复旧结果仍核对来源、运行和完整性。规划、预览和单独保存不生成参考。
- [x] 保存参考的响应丢失后可幂等重试；加入节点和打开画布失败只重试失败步骤。
- [x] 检查签名和按对象复用，保留版本、来源、预算和未知请求保护。
- [x] 当前有效结果与历史保留结果分别计数；失败状态无计划时不显示旧结果为当前成果。
- [x] 复用现有本地恢复与有限纠正，不新增审核循环或切换模型。
- [x] 记录程序阶段与复用原因，隔离回归两个入口并完整构建。
