# 分镜管理与画布清理 Implementation Plan

> **For agentic workers:** 本会话按用户“开始处理”的授权，使用当前会话与并行子代理实施并交叉复核，不再另设执行方式确认。

**Goal:** 从项目菜单和未导入提示进入分镜管理，并在删除画布时展示影响、选择回收独占内容，保留共享内容与追溯记录。

**Architecture:** 新增共享管理合同与独立后端模块，管理界面使用现有 Mantine 控件。画布仍负责节点制作；管理界面维护分镜内容和归属，删除预览在事务中重新验证依赖。

**Tech Stack:** React 19、Mantine 9、TypeScript、Fastify、SQLite、node:test。

**Spec:** 本会话用户接受的方案：项目级管理、当前画布方案默认筛选、场次/方案组织、可查看画布引用、字段编辑/排序/复制/回收/恢复/选择加入画布；删除画布默认仅节点连线，允许清理独占分镜及未保存候选，共享/已保存/成片引用素材保护，任务记录保留。

## Global Constraints

- 不改现有剧本和素材文件，不提交付费生成，不在用户现有项目上进行破坏性验收。
- 删除与回收分离；清理默认关闭；冲突后刷新预览并要求用户再次确认。
- 已保存素材、视觉设定、其他画布和成片引用内容必须保护；任务记录保留。
- 沿用现有 UI 组件和主题；窄屏可访问；不引入新依赖。

## Review Focus

- 默认画布的历史 NULL canvas_id 归属需要一致处理。
- 删除确认期间素材被保存/引用，必须阻止使用旧清理清单。
- 历史分镜、无场次分镜和跨画布共享分镜必须显示并可区分。
- 回收内容不得继续出现在导入提示/可选生成中，恢复不得重建失效引用。
- 切换项目/关闭页面/重复点击不得提交到错误目标或重复创建。
