# 分集草稿外层格式恢复

问题：重新设计第一集时，两次模型请求返回 HTTP 200，但阶段契约校验报告缺少 `artifacts` / `scenes`，并将场次字段列为根对象的多余字段。最新两次原始响应未持久化，无法确定是裸单场、裸场次数组或其他外层错误；旧候选缺少 `source_scene_id`，不得推断映射或直接写回。

修复范围：

- 仅对分集阶段成功完整返回的整段 JSON，识别严格合法、有动作/对白/旁白正文的单场或完整场次数组。
- 逐场全部通过才保留完整场次，顺序和内容保持；继续生成缺少的分集文稿，仍执行原场次 ID、完整覆盖、业务校验及独立复核。
- 数组的非法中项、未知字段、嵌套包装、多根对象、空或超限数组不能通过只取部分元素恢复。
- 保留最终失败的初始完整输出诊断，上限 100000 字符，标明原长和是否截断；不记录断流尾串，不将诊断当作已接受正文或完成标志，成功后清除。
- 强化外层格式说明；没有匹配契约候选时，格式修正优先指出完整 JSON 根类型问题，避免把数组内最后一场误报为整个结果。
- 空的工作项状态和诊断允许更新提示；已有或待修正文仍保留原检查点。

不修改正式数据库，不自动关联旧候选场次，不调用真实模型。验证使用临时数据库和模拟模型返回。

验证完成：9 个相关测试文件 183 项全部通过，覆盖完整根单场/1–100 场数组、非法中项不丢弃、原 ID 与漏场/改序保护、真实接口待确认草稿及失败诊断。完整构建、改动 `diff --check` 和独立代码复核通过。真实模型本次结果未复跑，原失败响应无法追溯恢复。
