# 独立分镜工作区验收

日期：2026-11-03 至 2026-11-04。代码保留在当前工作区，未提交、未推送。

## 实现范围

- 项目菜单「分镜管理」与剧本「规划分镜」进入同一全屏工作区，按场次组织镜头表和详情。
- 规划预览可编辑后独立保存，返回并选中保存方案；保存不创建画布、节点、参考设定或素材任务。
- 勾选后主动准备制作，绑定具体方案和镜头；待制作方案延迟创建画布，已有画布复用。
- 保留编辑、排序、复制、回收恢复、版本冲突及未保存导航保护；缩略图优先显示有效已选图片。
- 历史方案首次及后续场次制作都使用显式方案范围和来源版本，不借用最新方案的数据。
