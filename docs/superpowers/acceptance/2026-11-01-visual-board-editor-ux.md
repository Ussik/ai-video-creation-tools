# 设定图编辑器样式与交互优化验收

日期：2026-11-01

## 交付行为

- 设定图编辑区将主内容前置并默认展开，后接紧凑的可选补充区，最后展示画风、参考和生成设置。
- 保持单个可编辑文档，显示与复制顺序一致。旧稿中的补充内容按原相对顺序保留全部文字、空白、引用和来源身份；单纯打开不会写回提示词。缺少或存在多个主块时保持原文档。
- 主内容、补充区使用局部焦点反馈。差异与移除操作收入可键盘操作的菜单；待确认的来源更新保持可见。
- 参数摘要中的「调整参数」打开底部现有生成参数面板，参数变化同步摘要，相关自动要求按当前模型更新；以原生接口字段发送、无需改写正文的清晰度变化也能即时刷新摘要。高级文字编辑与冲突检查继续保留。
- 来源细节集中到「来源与修改记录」，优先展示待处理项。删除恢复、全文选中删除、剪切、粘贴、引用、撤销和候选编辑保持兼容。
