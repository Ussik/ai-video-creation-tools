# 成片工作台样式验收

修复桌面工作台的高度分配：顶部剪辑操作栏、三列预览/素材/设置区与底部时间线分别占位。预览按可用区域等比缩放；素材列表和设置内容各自滚动；片段与音频轨道分别横向滚动。窄屏切换为纵向页面流，不再使用桌面最小列宽。

真实浏览器检查尺寸：2048×1170、1512×833、1280×720、1024×768、768×1024、390×844。检查面板与时间线无重叠、后代高度不越过网格占位、页面无意外横向溢出。另检查768宽展开导航、四种设置页最后控件可达、手机时间线底部可达、横竖预览、素材预览及深浅主题。修改仅涉及布局，无项目业务数据保存。

前端验证：基础剪辑、原工作台、局部预览与配音预览共45项回归通过；架构/UI检查与web构建通过。
