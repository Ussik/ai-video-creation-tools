# 分镜管理与画布清理验收

日期：2026-11-01。使用独立临时数据库与 `buildApp()` 的 8001 服务验收，不启动生成 worker。页面项目为「分镜管理验收（隔离数据）」，与 8888 原工作区数据分离。

## 已验证行为

- 从项目菜单及未导入分镜提示进入管理；查看方案、场次、搜索与无场次镜头。
- 显式保存、复制、同组排序、回收和恢复；未保存草稿和旧 revision 冲突保护。
- 向非当前画布加入镜头、重复加入复用节点；修改分镜后再次跨画布导入使用新 revision。
- 删除默认不勾选清理，删除后镜头保持可用、画布引用清空。
- 可选回收独占镜头和候选，保留任务与文件；回收内容从常规流程隐藏，可分别恢复。
- 标题、剪辑备注修改保留选片和时间线；生成相关字段修改才失效。
- 恢复镜头时不会带回仍在回收站的输出；有效素材可独立于已回收的历史镜头使用。
- 删除弹窗与画布使用不同 React key，删除后旧画布卸载，不残留第二份画布。
