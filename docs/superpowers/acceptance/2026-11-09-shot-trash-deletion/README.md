## 删除范围

「彻底删除」移除回收记录，无法通过回收站恢复。删除镜头保留关联素材、历史任务、方案与剧本；删除素材保留本地媒体文件和历史任务，并清空历史任务输出指针。因此此功能清理列表记录，不释放媒体文件占用的磁盘空间，界面确认框与使用说明均明确说明。
