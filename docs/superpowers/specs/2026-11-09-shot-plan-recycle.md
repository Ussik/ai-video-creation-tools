# 分镜方案与批量回收

## Goal

让分镜管理支持把一个分镜方案或选中的多条分镜整体移入可恢复的回收站。

## Behavior

- 在活动分镜列表中选择单个方案后，可以将该方案的活动镜头整体移入回收站。
- 全选或手动多选镜头后，可以一次移入回收站。
- 删除采用软删除，保留方案、镜头、素材、生成任务和画布引用；回收站可以恢复镜头或整方案。
- 批量动作是全有或全无：任何镜头仍被画布、制作范围、进行中任务、剪辑、配音或导出引用时，拒绝整批操作并列出阻挡原因，不部分删除。
- 回收站恢复整方案时，只恢复该方案镜头，不改动其余方案。
- 活动方案筛选只列出仍有活动镜头的方案；回收站筛选列出含已回收镜头的方案。

## Scope

使用现有 `shots.deleted_at` 软删除字段和分镜管理 revision 乐观锁，不硬删除 `storyboard_designs`，不移除或改写画布节点及其素材/任务引用。

## Acceptance

- 选中一组无阻挡镜头后，确认一次即可回收全部镜头。
- 选择一个有活动镜头的方案并确认后，所有该方案活动镜头进入回收站，方案从活动筛选消失。
- 有任意阻挡时整批拒绝，UI 显示镜头名及阻挡原因，原数据完全不变。
- 回收站中的单镜头和整方案均可恢复。
- stale revision 返回冲突并要求刷新，不覆盖并发更新。
