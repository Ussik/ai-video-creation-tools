# 按栏目保留和展示剧本生成成果

用户要求：故事大纲中的概要设计完成就先保存，故事简述、背景设定等后续栏目继续处理；后续失败不能隐藏或丢失已完成内容。人物、场景和道具阶段使用同样的栏目粒度。

现有完整语义单元和完成栏目已同步保存在数据库检查点。本次把这些已落库的完整栏目作为可查看的待确认草稿提供给画布，保留原有确认后正式采用的流程。正式资料和生成中的草稿保持各自的数据来源，生成中的内容不自动进入下游制作或覆盖已确认原文。

- 每份完整栏目可以立即查看；未完成栏目不伪装成完整文档。
- 请求失败、重连、刷新页面后，已完成栏目仍可查看；接续沿用既有检查点。
- 完成整组草稿后仍可查看这些栏目；确认或放弃后对应待确认展示消失。
- 左侧按阶段列出全部已有栏目，明确标注“已保存草稿 · 待确认”。重新设计时可查看候选稿，正式原文不变。
- 不调用真实模型，不写用户业务数据；用临时数据库和模拟响应验证。
