# 分镜空场次与回收站删除

- 场次导航及移动筛选默认只显示当前标签、方案中有镜头的场次。提供「显示空场次」开关，保留从空场次开始规划的能力；不删除剧本源场次。
- 回收站提供单镜头、单素材、选中镜头批量彻底删除，以及清空整个项目回收站。清空不受方案、场次或搜索筛选影响，确认框明确全项目数量和不可恢复。
- 永久操作删除回收记录，不级联删除其关联素材、生成任务或剧本；媒体文件保留。删除镜头后其历史素材与任务通过现有外键解除镜头关联。删除素材时解除历史任务的输出指针。
- 操作只接受当前项目已回收记录，使用 revision 和立即事务，全部引用检查通过后才删除；任何阻挡拒绝整批且列出名称与原因。
- 复用现有画布、成片、制作范围、进行中任务、剪辑、配音与导出保护；素材还保护保存素材和视觉设定等引用。回收后产生的新引用也必须阻挡。
- 确认、请求期间锁定交互，取消不请求；409 要求重新读取。操作完成更新计数、选中项与筛选，隐藏空场次后不能卡在不可见的场次筛选。
