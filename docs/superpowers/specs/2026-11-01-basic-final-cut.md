# 基础成片工作台

用户目标：在成片工作台中完成素材导入、片段排序与裁切、替换配音、调整配乐和音量、添加字幕、连续预览与导出。以《傩王》90 秒预告验证完整流程。

每份剪辑独立保存名称、画幅、有序片段、旁白音频引用、配乐、混音和字幕。引用已有素材，不更改分镜顺序、候选选用、配音台词选用或项目级混音。允许重复使用同一素材，修改某份剪辑不会改变其他剪辑或已导出的文件。

基础交互使用前移/后移、重复/移除和明确的秒数输入。图片支持停留时长，视频支持入点/出点与原声音量。配音可使用项目内已有音频或上传替换，并编辑开始时间、取段和音量；新配音生成复用现有配音页。配乐支持选择、音量和人声出现时压低。字幕支持文本与开始/结束时间，预览显示并在导出时烧录。

使用显式保存和 revision 乐观锁。切换剪辑应保护未保存编辑，旧请求不能覆盖新选中的剪辑。导出读取指定 revision 的不可变快照，界面显示任务状态、错误及对应剪辑的下载入口。保留旧的按分镜选片入口以兼容现有工作。

约束：React 19 / Mantine 9 / Fastify / SQLite / 现有 FFmpeg；不引入依赖；保留工作区其他未提交改动；不调用收费生成；不提交或推送。新画布和剪辑仅追加《傩王》测试数据，原素材和原成片保持可用。

验收：创建两个剪辑并验证顺序、取段、配音和配乐互相独立；重复同一素材并独立裁切；并发保存返回冲突；错误归属/缺失文件/越界取段不能导出；字幕预览与实际输出一致；真实导出可解码且时长正确；《傩王》原剧本、原分镜、原画布与旧素材保持不变。
