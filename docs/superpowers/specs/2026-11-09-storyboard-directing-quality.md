# 剧本分镜的运镜与接镜质量

用户确认问题发生在「剧本生成分镜」，并授权直接进行专业优化。

- 先在结构化结果中确定整场固定锚点、人物站位、轴线工作侧、戏剧与节奏推进，再逐镜确定职责、摄影机运动的起点/触发/路径/落点/动机，以及明确切点和承接信息。
- 固定机位是有效选择；不为炫技增加运镜，不将反打或换景别误写为一镜内物理运动。不重复动作，不改变原文台词、因果、人物身份与创作者要求；允许有理由的省略、跳时和换场。
- 分镜生成使用既有分镜绑定，视频运动说明补充既有视频提示词绑定，不改默认或模型。显式选择基础规则时不额外加载外部技能。每阶段实际技能可查看。
- 新生成方案必须经过整组文字语义复核；仅对有证据的运镜、切点、连续性与来源矛盾提出问题。最多一次内容修订并再次复核；仍有错误则返回具体问题，不将未通过方案当作成功结果。
- 专业设计编译到现有镜头描述、首帧、视频与接镜字段，沿用当前预览确认保存和旧方案契约，无数据库迁移。新增质量摘要只描述文字检查，不声称真实影像质量已验证。
- 视频生成始终携带已保存的起止与接镜约束。图片转视频的语义分析得到同方案的直接前后镜，仅用于动作/空间/摄影连续性，不能借用邻镜台词；邻镜变更使分析失效。
- 不调用收费真实模型、不改用户现有分镜或技能数据。用隔离模拟验证合同、故障、修订和信息传递，真实艺术效果留待实际试用。
