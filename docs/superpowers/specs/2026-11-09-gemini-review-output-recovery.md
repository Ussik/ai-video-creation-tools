# 剧本审读输出超限恢复

用户已授权开始实现此前确认的修复方案。

- 保留完整有效原稿、候选文稿和创作者要求，审读结果可以分页；不因输出上限删问题、缩写正文或跳过整体一致性检查。
- 自动阶段审读维度再次超限后继续按完整问题分页；手动文档审读超限后使用同一分页机制。
- 保存经过格式、证据、范围和版本校验的完整结果；中断后只处理未完成项。
- 证据定位、问题归组也能在超限后分页。任何分页完成都必须通过原有整体业务校验。
- 重复且无进展时缩小单页，仍无进展则准确报错并保留断点；用户停止后不再发请求。
- 截断的工具调用永不执行；全部审读通过后才统一提交报告，正文不变。
- 记录实际结束原因和上游用量；输出预留不冒充实际输出额度。不得按 Gemini 名称硬编码厂商额度或思考参数。
- 既有模型配置、未提交工作和正常成功路径保持兼容。先使用隔离数据与模拟供应商验证；真实模型质量与网关额度须独立验证。
