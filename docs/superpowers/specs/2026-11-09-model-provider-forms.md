# 模型提供商表单与标准协议适配

用户已授权开始重构，以本机 Harness 的提供商、模型目录、模型选项分工为参照。Chat Completions 与 Responses 保持可选，不把任何已保存模型自动切换协议。

## 本轮交付

- 标准文本模型只需连接地址、凭据、模型 ID、协议及表单选项，不要求编写请求模板、响应路径或 JSON。
- 提供标准接口模式与原有自定义接口兼容模式。标准模式由后端按协议构造路径、输入包络、返回解析及输出/推理参数；自定义模式保留原模板。旧配置只读展示，不进行后台迁移；常见旧标准模板可在用户保存表单时无损迁入标准模式，不符合条件的模板保留自定义状态。
- 模型表单明确区分共享上下文容量（本地预检）、最大输出（实际请求）和高级输出预留。最大输出可以沿用上游默认（额度未知）或填写正整数，支持 K/M 输入。实际请求输出上限优先参与预检。
- Chat Completions 支持选择 `max_completion_tokens` / `max_tokens` 兼容字段；Responses 使用 `max_output_tokens`。提供协议兼容的推理强度及 thinking 开关表单，留空表示使用接口默认；不按模型名字猜测参数支持或额度。
- 展示最终实际输出字段和值、值来源，明确区分配置已发送与渠道已支持。切换协议保留兼容参数、能力、计费和自定义设置，不直接用起始模板覆盖全部设置。
- 图片沿用已有标准表单；视频补充现有标准协议预设的表单入口与常用画幅、分辨率、默认时长配置。非标准接口通过高级扩展入口兼容。
- 保持提供商与模型目录、现有模型 ID、用户选择和历史任务快照。新标准配置保存后必须经过原验证并在流式文本、工具调用和非流式文本三条路径生效；所有错误恢复和截断工具不执行的契约保留。

## 边界

本轮不增加未经实现的 Anthropic 原生协议，不猜测渠道能力，不读取或改写真实密钥，不修改用户数据库或自动设置现有 Gemini 输出额度，不调用真实生成接口，不提交或部署。静态界面和隔离模拟验收后再报告已验证结果。
