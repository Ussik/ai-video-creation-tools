# 加入画布弹窗各状态布局

实现目录：`/Users/caoyanzu/workspace/ai-video-creation-tools`，分支 `main`。仅修改前端布局、状态读取配合及离线验证；原有未提交改动保留。

## 固定布局

- 正文上部由 `ReferencePreparationRecovery` 提供一个状态区，集中进度、关闭后继续说明、未知/读取错误对应的唯一读取入口。
- 辅助行左侧保留数量，右侧 `查看旧参考 · 详情`；展开内容在正文，窄屏整组自然换行。
- 页脚左侧只在服务端 `inspection.can_cancel` 允许时显示弱危险色 `停止后续处理`。右侧为关闭和主动作；运行、停止中、读取失败、未获放弃等待能力的未知状态隐藏不可执行主动作。
- 关闭不请求停止；两个入口均保留原有作用域、结果采用和版本保护。

## 状态矩阵

| 状态 | 正文状态动作 | 页脚左侧 | 页脚右侧 |
| --- | --- | --- | --- |
| idle | 无 | 无占位 | 关闭 + 加入画布 |
| preparing | 进度、关闭后继续 | 仅服务端允许时停止 | 关闭 |
| running | 进度、关闭后继续；自动读取 | 允许时停止后续处理 | 关闭 |
| unknown | 核对状态，唯一入口 | 无 | 关闭；仅服务端允许放弃等待时显示带确认的重新整理 |
| partial | 未完成说明；逐项恢复保留 | 无 | 关闭 + 受能力约束的重试/继续 |
| complete | 新结果尚未采用 | 无 | 关闭 + 加入画布 |
| stale | 来源更新和旧参考保留说明 | 无 | 关闭 + 受能力约束的整理参考 |
| error（读取失败） | 重试，唯一入口 | 无 | 关闭 |
| cancelling | 正在停止并核对最终状态 | 无 | 关闭 |

主动作仍受原有模型、业务校验和服务端能力约束，未放宽任何生产门槛。普通状态不再手动常驻核对入口；已有有限轮询/聚焦刷新继续工作。本地 preparing 期间允许同一有界只读轮询取回服务端停止能力。

## 停止语义

核对 `canvas-preparation-runs.ts` 的 `cancel` 和执行信号：原接口标记 `cancel_requested`，停止本地执行/后续请求，不能保证上游已经取消，已有结果保留。未修改后端策略。

增加前端确认：`已发出的模型请求可能仍会继续，已完成结果会保留；这不代表上游请求已取消。` 确认绑定 run/owner，运行更换时禁用；同步锁阻止重复确认。
