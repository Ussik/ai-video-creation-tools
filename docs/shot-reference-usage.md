# 分镜参考的使用范围

场次设定提供可选的人物、场景和道具资料。镜头引用另行保存每个对象的使用范围，决定开镜图片与视频过程各自需要的参考。

| 用途 | 开镜图片 | 视频 |
| --- | --- | --- |
| 图片与视频（both） | 使用 | 使用 |
| 仅开镜图片（image） | 使用 | 不使用 |
| 仅视频过程（video） | 不使用 | 使用 |
| 本镜头不使用（none） | 不使用 | 不使用 |

在画布的“镜头引用”中调整“使用范围”，会立即保存。对象的设定版本、已确认参考图和历史参考快照仍然保留。“必需”只在该对象适用于当前生成类型时要求先确认参考图。

图片与视频分别使用同一份用途筛选结果来生成文字设定、自动参考连线、实际参考图片列表和待补齐提示。只出现在视频后续动作中的人物不会阻塞开镜图片。背景中可见的对象也应保留；只有画外提及或仅提供光色的对象无需强制入画。

分镜提示词保留固定视觉特征，以及本次实际选择的独立参考图角度和用途。设定板制作的三视图、拼版、多状态或全套细节视图需求不再追加到分镜提示词；这些需求仍用于制作对象的设定参考图。

分镜规划后的参考设定整理会输出 `shot_usage`，逐一指定每个已规划镜头的用途，确认后事务保存。未被新整理结果使用的场次候选保持为 `none`。既有对象的定义、已确认图和参考快照不因用途调整而替换。并发修改引用后，旧预览或旧整理草稿会被拒绝，避免覆盖新决定。

旧接口省略用途时保留已保存用途，新绑定默认兼容原来的 `both`。数据库升级不猜测旧镜头的出镜内容；旧镜头可以在引用管理中调整，或重新规划并整理参考。《言灵》首场五镜的既有用途已根据现有图片、视频和状态描述修正，修正前的数据保存在本机 `data/backups/`。
