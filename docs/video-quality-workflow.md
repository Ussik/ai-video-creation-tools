# 视频动作检查与成片复核

视频提示词整理、生成时长、动作对照和实际成片复核分别处理，保留创作者当前正文与已有素材。

- 视频阶段显式加载已安装的动作编排、可生成性、提示词语法、视觉运动和质量门槛资料；整理结果可展开查看实际加载文件。不会自动安装或替换技能。
- 视频整理默认由界面发起独立动作/剧情核对，报告主次动作、起止状态、可见结果、事实保留和风险。当前基稿优先于旧分镜正文；已明确允许修改的对白可调整，其他已识别的逐字对白遗漏会触发一次有界修正。内容核对属于模型建议，不能代替成片判断。
- 支持图片理解的文本模型可以启用真实参考图诊断；目前最多读取实际参考列表前八张。未提供像素的图片明确标为未查看，不伪称看图。不支持图片理解时仍可使用文字整理。
- 显示生成时长、素材实长和计划入片时长。它们相互独立，不会自动延长分镜、裁切素材或修改时间线。
- 视频节点菜单和视频预览可打开“动作对照”或“成片复核”。对照冻结基准请求、模型与提供商配置、参考文件校验值，候选只改提示词，输入变动会阻止提交，重复提交复用同一任务。没有原始生成任务的上传视频可复核，不能作固定请求对照。
- 复核支持显式配置的视频理解模型（Chat Completions / video_url）或图片理解模型。后者接收带时间标签的真实抽帧，报告明确保留连续速度、滑步和接触瞬间的不确定性。目前两种模式都不宣称验证音轨、逐字对白或口型同步；未提供独立设定和相邻镜头时，也不宣称完成跨镜连续性审查。
- 问题报告保留时间段、期待与观察、证据帧、建议剪辑区间、模型和输入上下文。点击时间位置可定位原视频。源文件或分镜变化会标记过期，旧证据接口拒绝以新素材冒充旧证据。
- 复核不会自动批准/拒绝素材、替换入片选择或触发重生成。

接口：

- POST `/api/projects/:id/skills/refine-prompt`：视频可传 `check_video_content` 与 `analyze_reference_images`，返回 `diagnostics` 与 `loaded_files`。
- GET/POST `/api/projects/:id/assets/:assetId/video-reviews`：历史/创建报告。
- GET `/api/projects/:id/assets/:assetId/video-review-frame`：带报告签名的证据帧。
- GET/POST `/api/projects/:id/video-comparisons`：历史/准备固定条件对照。
- POST `/api/projects/:id/video-comparisons/:comparisonId/start`：使用原生成队列提交候选。
