## 实现

- 公共 AI 请求使用独立 IndexedDB 身份库，只保存 ID、输入指纹、路由与时间，不保存正文、提示词或模型结果。
- prepare 与 complete 等待事务 oncomplete；put 成功但事务中止不算持久化。终态校验 pending ID 后原子转为 completed；失败时保留原身份，后续只查询。
- 旧 pending 精确迁移，完成提交后才写兼容标记；标记故意不是合法 JSON，使旧客户端解析失败并停止发送。新旧身份冲突、坏记录和标记无副本均拒绝新派发，不覆盖或清除记录。
- 同页合并及跨标签页 Web Locks 保留，排队调用异步读取 pending/completed，恢复只查询原 ID。取消与未知结果不会授权换 ID。
- IndexedDB API 缺失时保留旧路径；访问或事务失败不降级为另一份身份或内存提交。
