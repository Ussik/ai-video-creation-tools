# 剧本任务的超时、恢复与质量边界

后端持有任务，浏览器订阅 SSE。离开页面、刷新和网络断开只移除订阅；“停止生成”才取消任务。前端每连续 60 秒收不到服务事件会重连同一任务，重连间隔按指数退避并加入抖动，最大约 37.5 秒。后端每 15 秒发送心跳。

## 执行预算

| 范围 | 累计预算 |
| --- | --- |
| 普通讨论、意图判断、工具决策 | 5 分钟 |
| 上传剧本目录单页输出（每次仍携带全文） | 15 分钟 |
| 原文证据校验或局部格式修正 | 10 分钟 |
| 全剧整合单项输出、共同骨架 | 20 分钟 |
| 当前阶段生成或问题补齐 | 30 分钟 |
| 全文独立复核 | 20 分钟 |
| 整轮主动执行 | 120 分钟提示，180 分钟停止并保留进度 |

模型普通请求连续 5 分钟无上游事件会停止，非流式和配置了推理的请求允许 10 分钟。服务心跳不能刷新模型计时。嵌套工作使用父级剩余预算。格式修正和网络退避计入当前步骤，网络重试与格式修正最多共 3 次模型尝试；网络故障本身只自动重试一次。429 遵守 Retry-After。认证、额度和配置错误直接停止。

等待创作者回答、处理设定问题或预览确认时，本轮任务已返回，不继续占用主动执行预算。

## 三种操作

- **重新连接**：查看正在运行的同一个任务，不发起新推理。
- **继续未完成步骤**：保留任务和对话 ID，重新检查来源、模型配置、技能、候选与待确认草稿版本。复用仍匹配且重新校验通过的步骤。
- **重试本轮/重新生成**：新一轮请求，兼容的阶段检查点仍可能复用；原回复保留在历史记录。

服务重启会把运行中的创作任务标为中断，之后由创作者明确继续；上传分析队列会保留与当前全文流程兼容的分析检查点并重新排队。已保存文档不盲目重放。任意工具对话不提供自动重放承诺，只有已知可恢复的阶段、补齐或只读讨论任务开放继续入口。

阶段候选稿、补齐结果、全文分析和独立复核保存检查点，复核连接出错时不必重写已完成的候选稿。补齐后的拟有效稿也按全文分析流程处理。缓存匹配包括原文、创作要求、候选状态、模型及处理结构版本；各检查点命名空间分开存储，旧切批流程的中间结果不能冒充新版全文分析完成。

上传分析的目录输出在正文超过 16,000 字符时分页，目标每页约 8,000 字符的产出范围，优先集、章等语义标题，长连续正文按完整句段边界划分。每页请求仍发送全部原文，模型只返回本页目录和证据；完整合法的页及其证据修复结果持久化，中断只重试未完成页。正文超过 32,000 字符或目录超过 80 段时，全剧整合按概览、人物、时间线与伏笔分项输出并保存，每项继续读取完整原文与完整目录。最后仍需全文覆盖、事实来源及独立质量核对全部通过。

失败与暂停保留具体阶段及上次处理项。恢复说明区分只有原稿、已有目录页、目录已完成、已有部分整合结果、逐项质量修补和只差独立核对；没有合法分析检查点时不会宣称已保存分析成果。v5 全文流程的有效目录、整合及核对结果保留，旧片段摘要流程不直接升级为就绪。普通质量问题不清空完整目录和全剧信息，继续时逐项修补并保存进度，全部修补后再做全文独立核对；复核连接中断只继续复核。确认修订后旧目录候选的理解失效，或问题涉及章节边界等无法安全局部修补时，才进入一次受控重建；中途失败后保留该轮的新进度，重建后复核仍有问题则停止。

剧本最多 100,000 字符，超过上限直接拒绝。上限以内始终完整发送有效稿，不再根据字符数切批、选片段或预先将阶段拆成逐栏目、逐八集生成。所选模型不能容纳完整输入时明确停止。若上游明确报告输出额度耗尽，则保留完整合法单元，按完整语义块接续剩余成果，每次继续携带完整有效稿、要求和已有成果。接续仍受累计步骤预算、轮次与无进展限制；中断后可恢复已校验单元，不复用残缺 JSON，也不自动裁掉原文。

## 可选的提供商后台响应

仅在提供商确认支持 OpenAI Responses 后台响应和按 ID 查询时，才在文本模型高级设置中配置 `background_responses: true`。默认关闭，不会更改已有模型设置。

该能力用于后端持久任务内的只读结构化请求，提交 `background: true, stream: false`，立即保存 response ID，随后轮询查询。网络断开或用户继续中断任务时，优先查询已有响应，不重建推理。当前采用查询模式，不依赖供应商的流事件游标兼容性；函数工具回合保持原调用协议。

明确停止会请求提供商取消已接受的响应；服务关闭保留 ID 供恢复。提交结果不明且没有 ID 时停止自动重发；响应过期或不可查询时显示原因，由创作者核对后重新发起。提供商存储窗口不是本地持久化保证。

## 创作质量

超时与恢复不减少原文证据覆盖，不修改不可变上传原稿，不跳过结构、精确定位、跨文档和独立复核。补齐读取完整有效稿与当前完整候选稿，恢复后沿用已接受的候选变更。生成检查点不等于审核通过；只有全文独立复核通过后才提供可确认草稿，正式文档及有效稿仍在用户确认保存时更新。
