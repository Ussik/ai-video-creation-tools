# 标准音色配音

[返回文档](README.md) · [剪辑与导出](basic-final-cut.md)

为角色对白和旁白生成音频，试听后选用，再安排到成片中。当前合成接入豆包语音合成大模型 2.0 的标准音色，需要独立的语音服务 API Key。

**入口：** 画布顶部项目名旁的“切换创作页面” → **配音**；也可点击成片工作台顶部的 **配音**。

[制作第一句](#入口与流程) · [放进成片](#成片预览与导出) · [批量与改稿](#批量处理与剧本改版) · [常见问题](#常见问题)

## 入口与流程

```mermaid
flowchart LR
    A[配置语音服务] --> B[给角色选择声音]
    B --> C[导入或填写台词]
    C --> D[生成候选并试听]
    D --> E[选用此版本]
    E --> F[安排入片位置]
```

### 1. 配置语音服务

打开 **全局语音配置**，填写新版语音控制台 API Key。这个密钥独立于图片、视频模型的密钥，配置后供所有项目使用。

### 2. 给角色选择声音

在 **角色声音** 新增角色或旁白，搜索标准音色，设置默认表演与语速后保存。可先点击“试听”听官方样音；样音播放不发起语音合成。

### 3. 准备朗读正文

在 **台词与旁白** 手动添加一句，或展开 **从剧本导入**，勾选场次再导入。导入后检查说话人，给未识别的台词手动分配角色。

| 内容 | 填写位置 | 示例 |
| --- | --- | --- |
| 真正要念出的文字 | 朗读正文 | “门外有人。” |
| 怎么念 | 表演要求 | 压低声音，停顿后说最后两个字 |
| 发生了什么 | 情境参考 | 角色刚听到门外脚步声 |

表演和情境通过语音指令提交，不会拼进朗读正文。

### 4. 生成并试听候选

点击 **生成配音**。完成后在候选列表试听，点击 **选用此版本** 保存到资产库。重新生成会新增候选，旧版本保留原始文本、音色和表演信息。

### 5. 安排入片位置

选用完成后，按你使用的剪辑方式操作：

| 剪辑方式 | 操作入口 | 位置依据 |
| --- | --- | --- |
| 按分镜选片 | 配音页的“配音入片”，或成片右侧的本场台词 | 起始镜头 + 相对时间 |
| 基础剪辑 | 右侧“配音” → 选择音频 → “添加配音” | 当前独立剪辑的成片开始时间 |

**选用候选与加入成片是两个步骤。** 只有选用，没有安排播放位置，成片中不会自动出现这句配音。

## 成片预览与导出

### 按分镜选片

1. 在 **配音入片** 选择起始镜头，填写相对时间、音频入出点与音量。
2. 点击 **加入成片**；已有入片记录时，按钮显示 **更新入片配音**。
3. 到成片工作台查看对白区间，并用 **实际入片** 或 **连续预览** 检查混音。

配音可以跨镜头播放；镜头重排后，起点跟随锚定镜头。同一句配音在不同分镜方案中的入片位置分别保存。项目配乐与混音设置仍在 **成片设置** 中管理。

### 基础剪辑

生成候选后，返回基础剪辑的 **配音** 页，点击 **刷新音频素材**，添加或替换音频，再调整成片开始位置、取段与音量。具体步骤见[成片工作台](basic-final-cut.md)。

独立剪辑拥有自己的配音、配乐和字幕。这里替换音频，不会改写配音页的选用结果或其他剪辑。

## 批量处理与剧本改版

| 你想做什么 | 使用的操作 | 需要确认的结果 |
| --- | --- | --- |
| 补齐尚未生成的台词 | 筛选、勾选后“生成缺失配音” | 已有当前版本候选和正在生成的台词会跳过 |
| 为多句选取有效版本 | “选用有效候选” | 选最新且与当前文本、音色、表演、语速匹配的成功候选；仍需安排入片 |
| 将改稿带入配音台 | “同步所选场次”或“同步本场剧本” | 先查看新旧差异，再确认同步 |
| 沿用剧本已移除的旧台词 | “保留为手动台词” | 历史台词与候选继续保留 |

修改文本、表演、音色或语速后，旧选用版本会提示需更新。选好新候选后，还需确认 **更新入片配音**，成片不会静默换成新声音。

## 常见问题

### 有候选音频，为什么导出后听不到？

先确认是否已选用，再确认是否已在当前分镜方案或独立剪辑中设置播放位置。基础剪辑还需要保存修改并重新导出。

### 官方样音和实际生成的表演不同？

官方样音使用固定文本与表演。角色语速、表演要求和情境参考只在实际合成时生效。

### 合成中断后会自动扣费重试吗？

失败、断流或服务重启后不会自动再次合成。任务记录提供 **返回配音**，先核对服务商记录，再手动生成新候选。

### 支持声音复刻或自动对口型吗？

当前配音页使用标准音色，没有接入用户声音复刻和自动口型同步。按分镜入片需手动安排位置；基础剪辑支持另行编辑字幕。

## 服务协议

| 项目 | 配置 |
| --- | --- |
| Endpoint | `POST https://openspeech.bytedance.com/api/v3/tts/unidirectional` |
| 请求头 | `X-Api-Key`、`X-Api-Resource-Id: seed-tts-2.0`、请求 UUID；请求 usage 字符数 |
| 正文 | `req_params.text` / `speaker`；`additions` 为 JSON 字符串，`context_texts` 传表演指令 |
| 输出 | MP3、24 kHz；逐行解析流式 JSON，结束码 `20000000`，音频解码通过后保存候选 |
| 单次限制 | 正文最多 5000 字符，等待上限 3 分钟；排队或运行中的台词不能重复提交 |

导入长场次文本时按句子边界分段。明确的 `角色：台词` 标签用于角色分配，前置括号提示拆入表演要求。字幕时间戳与实际音频时长分别保存。超过 300 条的批量操作会分批提交。

### 音色目录

2026-10-13 的快照收录 466 种官方标准、预设角色与外语音色。可按名称、Speaker ID、语种、性别和场景搜索；目录位于 `packages/shared/src/media/speech-voices.ts`。

官方样音来自公开控制台，播放不需要语音 API Key、不创建项目任务。未收录的标准 Speaker ID 可手动填写，但不提供样音。用户复刻的 `S_` 音色被拒绝，官方预设角色的 `ICL_` 可用；实际合成权限取决于账号开通的服务。

### 同步与导出校验

剧本同步优先匹配未变化的内容，再保守匹配角色明确的修改；无法确认时新增台词并保留旧历史。手动修改与正在生成的台词受到保护，音频候选不删除。

按分镜导出会校验素材、版本与制作范围。旧入片版本、已删除的起始镜头或超出范围的音频需先处理；未入片的已选配音会提示。导出任务保存音频和混音快照，后续编辑不改变已排队任务。
