# 标准音色配音

项目使用豆包语音合成大模型 2.0 的标准音色，为角色对白和旁白生成独立 MP3 音频。官方标准音色可用于对白与旁白；每个角色固定 Speaker ID，单句调整表演。当前不接入声音复刻槽位。

## 入口与流程

- 画布顶部项目名旁的“切换创作页面”菜单 → 配音；成片工作台顶部也有“配音”。任务记录页的失败配音任务提供“返回配音”。
- 打开“全局语音配置”，填写新版语音控制台 API Key。它与方舟图片、视频的密钥独立，适用于所有项目；本机 SQLite 仅保存密文，接口只返回是否配置。
- “角色声音”新增角色/旁白，为每个角色选择标准音色；下拉框内可搜索，并按“全部 / 男声 / 女声”分类筛选。设置默认表演和语速后保存。
- “台词与旁白”手动添加台词，或展开“从剧本导入”，勾选场次再导入。明确的 `角色：台词` 标签会分配角色，括号中的前置表演提示拆入表演要求；没有明确说话人的内容需要手动分配角色。
- 编辑朗读正文、表演要求和情境参考；点击“生成配音”才会创建合成任务。表演/情境通过语音指令提交，不拼入朗读正文。
- 在候选音频中试听，点击“选用此版本”保存到资产库。修改台词或角色声音后可生成新候选；旧版本保留原始文本、音色和表演快照。
- 选用后，在“配音入片”选择起始镜头，设置相对镜头起点的时间、音频入出点和音量，再点击“加入成片”。也可在成片工作台右侧直接处理本场台词。配音可以跨镜头播放，镜头重排后起点跟随所锚定的镜头。

## 批量处理与剧本改版

- 可按场次、角色、状态筛选并勾选台词。“生成缺失配音”跳过已有当前版本候选和正在生成的台词；“选用有效候选”选择与当前文本、音色、表演和语速一致的最新成功候选。超过 300 条会分批提交。批量选用不自动安排入片位置。
- 剧本变化后，用“同步所选场次”或台词中的“同步本场剧本”查看新旧差异并确认。同步先按未变化的内容匹配，再保守匹配角色明确的修改；不能确定对应关系时新增台词，并把旧台词保留为历史。手动修改和正在生成的台词受到保护，音频候选不会被删除。
- 剧本移除的台词和旧候选仍可查看。需要继续使用旧对白时，可明确“保留为手动台词”。修改台词、表演、音色或语速后，旧选用配音会显示需更新；选择新候选后，还需确认“更新入片配音”，不会静默替换成片中的音频。

## 成片预览与导出

- 底部时间线按实际剪辑时长显示画面、对白/旁白和全片配乐。点击对白区间可定位对应台词；无重叠的对白共用一行，重叠的对白分行显示。
- 当前镜头的“实际入片”和“连续预览”读取同一套配音位置、取段、音量和混音设置，支持暂停及进度跳转。“原始素材”用于查看未经剪辑混音的原素材。
- “成片设置”统一管理项目画幅、背景配乐和配乐音量，可分别开启对白播放时降低配乐、降低视频原声。配音的取段边缘使用短淡变；0% 静音配音不触发音量降低。当前导出固定为 720p、24fps。
- 导出会验证配音素材、版本和播放范围。旧入片版本、已删除的起始镜头或超出制作范围的音频必须先处理；已选用但未入片的配音会提示，可明确选择导出当前成片。导出任务保存音频和混音快照，后续编辑不改变已排队的导出。
- 当前未实现自动逐句排布、字幕编辑/烧录、口型同步和独立音效轨。角色对白应通过配音入片设置使用，背景音乐在成片设置中单独选择。

## 服务协议

- Endpoint：`POST https://openspeech.bytedance.com/api/v3/tts/unidirectional`
- Headers：`X-Api-Key`、`X-Api-Resource-Id: seed-tts-2.0`、请求 UUID；请求 usage 字符数。
- 正文：`req_params.text` / `speaker`，输出 MP3、24 kHz；`additions` 为 JSON 字符串，`context_texts` 传表演指令。
- 逐行解析流式 JSON；结束码 `20000000`，音频解码通过后才能保存候选。字幕时间戳与实际音频时长分别保存。
- 单次合成等待上限 3 分钟；失败、断流或服务重启中断均不会自动再次合成，避免重复计费。用户核对厂商记录后，可手动生成新候选。
- 单条正文上限 5000 字符；长场次文本导入时按句子边界分段。单条台词排队/运行时禁止重复提交。

截至 2026-10-13，已收录官方 2.0 列表的 466 种音色，包含标准音色、官方预设角色音色和外语音色；可按名称、Speaker ID、语种、性别和场景搜索。角色声音旁的“试听”直接播放官方控制台公开样音，无需语音 API Key，不发起合成、不消耗合成额度、不创建项目音频或任务。切换音色、试听其他角色、切换页签或关闭配音会停止当前试听；加载失败会提示重试。样音使用官方固定文本与表演，角色语速和表演设置在实际生成配音时生效。

音色名称、用途与语言来自官方文档，样音地址来自官方控制台；目录快照保存在 `packages/shared/src/media/speech-voices.ts`，不依赖登录控制台来展示或试听。仍可手动填写其他标准 Speaker ID；没有收录的音色不提供官方样音。服务端拒绝用户复刻的 `S_` 音色，官方预设角色的 `ICL_` 音色可以使用。实际合成权限以账号开通的 2.0 服务为准。
