# Seedance 2.0 提示词整理

依据 [Seedance 2.0 系列提示词指南](https://console.volcengine.com/ark/region:cn-beijing/docs/ark/seedance-2-0-prompt-guide?lang=zh) 与[系列教程](https://console.volcengine.com/ark/region:cn-beijing/docs/ark/seedance-2-0?lang=zh)，2026-10-10 核对。当前 Mini 型号 `doubao-seedance-2-0-mini-260615` 属于适用范围。

## 整理提示词

视频节点选择 Seedance 2.0、Fast 或 Mini 后，“整理提示词”会按当前模型名称、远程型号或显式提示词方言加载 2.0 专用参考资料。外部技能仍由创作者选择；即使不使用外部技能，内置的 2.0 整理要求也会生效。不会自动安装、更新或修改外部技能文件。

整理仅处理当前节点，保留已确认剧情、逐字对白、比例、时长、生成模式和实际参考顺序。结果仍是可编辑草案，点击“应用提示词”后才更新节点。

- 使用节点已保存的逐图用途；整体构图、比例尺度、动作和开场/过程/结尾状态参考仅继承相应用途，图片顺序不代表时间顺序，也不自动将分镜图视为首帧。
- 用稳定的角色名称定义主体，说明实际参考图分别用于面部、服装、场景或道具。同一人物的不同视角属于同一身份，不能变成多个角色。
- 图片编号对应本次实际提交顺序，支持“图片1”或“@图片1”；不把内部资产 ID 当作模型能识别的图片指代。
- 动作写清肢体、方向、幅度、速度和衔接；用可见细节表达情绪。剧情要求的快速动作保留，不自动改成慢动作。
- 连续镜头尽量使用一种主要运镜；只有节点本来包含多个内部镜头时才写镜头序号。按事件顺序组织，精确时间戳不视为切点保证；接口总时长保持原值。
- 用 `{}`、`<>`、`（）` 区分台词、音效和音乐，默认不添加字幕、额外 Logo 或水印；创作者明确要求的字幕与画内文字保留。
- 保持参考、编辑和延长的任务类别；不新增未绑定的音频或视频编号，也不声称读取过未传入的素材。

## 人物参考选择

“按镜头推荐”优先选择已确认、当前修订和画风的独立图片：面部身份图在前，镜头对应的一个身体视角在后。背面镜头只推荐背面图，不额外加入正脸。没有指定机位时优先采用默认身体图，否则从正面、四分之三、侧面等适用视角中选择；有独立面部图时可以使用面部图。

推荐不会一次选入所有角度或将人物布局图作为身体参考。信息图回退仍可使用，但官方提醒人物三视图拼板可能造成身份混淆；优先准备独立面部与全身图，只有镜头需要时才加入其他角度。已有镜头的引用顺序不会自动重排，手动选择仍按保存顺序提交。

## 配置边界

2.0 系列官方图片上限是 9 张，分镜构图图也计入。已有模型可显式设置 `max_reference_images: 9`，无需套用完整预设；这会保留原有视频参考模板以及编辑、延长模式。超限会在整理、预览和生成时拒绝，不会自动删图。更低的自定义上限仍有效。

提示词方言识别不会根据模型名称推断接口能力或重写连接配置。图片媒体尺寸与请求体限制继续由显式 `video_reference_profile` 开启；“应用 Seedance 2.0 配置”仍是单独的图片参考预设操作。

当前整理接口提供实际图片顺序与逐图用途，并按镜头的视频出镜范围及排除项筛选对象；不传入视频或音频绑定。视频生成链路可按已有模板提交参考视频；音色参考和多视频参考需另行接入后才能用于自动整理。提示词规则不能保证完全避免换脸、重复人物、字幕或衔接跳变，仍需检查实际产物。
