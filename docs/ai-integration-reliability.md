# AI 接入可靠性与结果恢复

首轮增强基于已合并并推送的 main `2c2b700`，原增强分支为 `codex/ai-integration-reliability`。后续在 `codex/langfuse-observability` 接入本机 Langfuse，并引入 LangGraph 编排场次分镜；继续使用现有 Fastify、SQLite 和模型适配器。LangChain Core 仅为图运行依赖，不替换现有模型适配器；未接入 LangSmith。详见 [LangGraph 分镜可靠性](./langgraph-storyboard-reliability.md) 和 [Langfuse 配置](./langfuse-observability.md)。

## 已实现的行为

- 短 JSON 创作请求在执行前保存操作身份，发送响应前保存结果。已保存的最终结果可按原身份读取或重放；尚无最终结果的运行中或中断操作返回原状态，不自动重新生成。主动开始下一次生成使用新身份。浏览器保留未确认身份，同页并发合并，支持 Web Locks 时也协调跨标签页调用。已有画布候选 `Idempotency-Key` 继续由原提交协议管理。
- 覆盖剧本文档与聊天、场次/片段分镜、提示词整理与复核、原稿分析启动、视觉设定、画布分析和方案、连续性与成片复核、媒体及配音提交等当前 JSON AI 入口。入口清单位于 `packages/shared/src/api/ai-operations.ts`；长任务、SSE 和任务控制继续使用各自的领域任务身份。
- 错误保留安全的类别、原因、是否可恢复、结果确定性和恢复动作，区分鉴权、限流、上下文容量、输出截断、拒绝、契约、来源冲突、取消和未知结果。来源冲突、取消及内部校验器错误不会被当作格式错误再调模型修正。
- 原稿分析保存请求准备、实际派发、完整原始结果及 Responses 上游身份。重启时优先找回已完成结果或查询原响应；未知受理的普通请求不会自动重发。完成结果落库失败仍保留派发屏障；取消发生在完整响应之后时，先保留结果。旧版运行/排队记录缺少派发证据时转为待核对失败状态，保留旧成果。
- 分镜和提示词把“执行完成”与“质量通过”分开。复核失败或不能下结论时保留完整候选；可以编辑并只复核。编辑使旧凭证失效，但保留历史问题。分镜正式保存需要服务端签发、与候选、来源和模型配置一致的通过凭证；幂等提交仍可返回已保存结果。
- 分镜修复只替换有当前复核依据的目标镜头，程序复制其他镜头。身份、声音计划和未授权时长保持不变；重估模式下仅明确授权的目标可调整时长。场次分镜的修复和复查携带最新正式分集正文及来源优先级；独立片段使用片段原文、本次要求及适用的项目约束。
- 媒体任务区分本地准备与可能付费派发。派发登记失败会阻止 POST；已经生成的本地文件在最终事务前登记摘要和大小，可在原任务重试时校验后接管。视频必须完整解码且有有效画面和时长；HTML、JSON、音频文件及损坏视频不能作为视频成果交付。
- 失效结果链接可以查询原上游任务刷新一次，不会新建付费任务。TTS 使用持久请求编号，失败信息保留编号；没有可接管本地结果的未知语音请求不会自动重新合成。旧执行者不能覆盖已经取消或变更归属的任务。

## 使用与接口

任务记录中新增“AI 创作处理记录”，可查看已保留的创作内容及质量状态，并请求停止仍在本地运行的处理。场次分镜支持“复查当前草稿”和“仅修复已确认问题”；片段分镜支持复查当前草稿。质量尚未通过时不能正式保存。提示词候选同样可以只复查后应用。

- 请求身份：`x-ai-operation-id`。
- 读取原结果：`GET /api/ai-operations/:operationId`，或项目内同名路由。
- 项目列表：`GET /api/projects/:id/ai-operations`，最近 100 条。
- 本地停止：`POST /api/ai-operations/:operationId/stop`，返回 `remote_cancelled: false`，不表示上游已取消或免计费。
- 只有带机器码 `ai_operation_not_found` 的权威不存在响应，才允许用户下一次明确重试原身份；离线、未知响应和过期执行租约都不会自动重新派发。

## 验证边界

验证使用临时数据库、模拟网络和本地 FFmpeg，不调用真实付费端点，不修改正式项目数据，不启动或重启用户服务。自动测试验证防重、恢复、质量闸口、媒体完整性和界面行为；不据此宣称真实模型质量、网关稳定性或生成耗时已改善。

场次分镜规划由原领域任务保存候选并支持明确续跑；片段分镜在审查前保存完整候选到原操作记录，恢复后须重新复查。提示词虽保存内部步骤，但尚未提供审查期间进程退出后的候选直接恢复入口。

进程中断后若上游没有可查询身份，记录只能保留为未知并要求核对提供商记录。公共 HTTP 层不会接管领域任务执行，也不会自动从中断处重新生成。媒体本地成果和准备记录由原任务的重试入口接管，不新增启动时自动重排逻辑。脚本创作及原稿分析没有新增累计请求、token、修复轮数或业务总时长上限。
