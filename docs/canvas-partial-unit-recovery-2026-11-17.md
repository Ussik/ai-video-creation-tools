# 画布准备的单元级恢复

本轮继续在 `main` 工作区增量修改，没有调用真实模型、重置检查点或提交推送。

视觉设定准备现在按对象单元处理。已通过校验的对象立即进入返回结果并保留检查点；确定性的锁定字段冲突、历史候选耗尽等错误只记录对应 `unit_key`，整批返回 `status: partial`。下一次请求可以只携带 `unit_keys` 继续失败对象及其基础依赖，或携带 `skip_unit_keys` 明确跳过对象。网络断连、取消和未知投递结果不会被转换成部分成功。

加入画布前端展示部分完成和待处理对象，重复点击不会重新选择技能或重复成功对象；同一历史冲突仍由既有不可重试状态阻断。刷新未变化资料不会解除阻断，改变模型、技能或资料签名后才重新交给后端判断。生产准备弹窗也支持跳过失败对象，跳过结果必须再次经过当前范围和引用校验。

观测事件新增 `task_id`、`unit_key`、`checkpoint_source`、`is_new_model_call`、`recovery_type` 和 `attempt`，本地迁移记录为 `original_raw`/`local_migration`/`false`，单元阻断记录为 `blocked`，部分批次记录为 `partial_batch`。这些字段只经过固定格式筛选后进入现有模型结果观测链路。
