# 多节点画布性能

实现基线：2026-10-22，提交 `9ba5a25`。本轮核对当前实现，未重新运行浏览器性能基准；下文测量均为历史开发环境样本。

当前单张画布最多保存 500 个可编辑节点和 1000 条连线，固定项目剧本引用节点另行保留。超过 32 个节点、超过 48 条连线（含自动参考连线），或至少有 8 个图片/视频/生成节点时，画布启用 React Flow 的可视区域渲染。节点按可视区域挂载，连线按其边界与视口相交情况挂载；跨越视口的长连线仍可能保留。屏幕外节点仍保存在完整图中，继续参与搜索、框选、全选、连线输入、自动保存和撤销。

所有缩放级别都保留节点的真实文字、图片和视频封面，方便缩小后纵观全局。大画布缩放到 45% 或更小时，未单独选中的媒体节点使用最长边 320px 的缓存预览，并减少细小操作控件与阴影；放大后恢复 640px 预览。单选继续提供原图、视频播放器或文本编辑器。节点尺寸与连接端口保持，缩放只影响展示，不改变节点数据。

文本编辑器仅在单选文本节点时创建，多选使用内容预览。未选中的图片使用最长边不超过 640px 的 WebP 缩略图，单选后加载原图；视频默认显示首帧封面，仅单选时挂载原始视频播放器。视频离屏或切到后台时暂停，取消选中时暂停并卸载，重新选中后由用户手动播放。图片继续采用浏览器懒加载与异步解码。缩略图失败时图片回退原图，视频显示静态占位；单选视频仍可播放原文件。

`GET /api/assets/:id/preview?size=640` 支持 320、640、960 三种尺寸，在项目媒体目录的 `.previews` 中缓存结果。源文件路径、大小或修改时间变化后缓存失效；并发请求去重，同时最多进行两项缩略图/视频取帧任务。接口支持 ETag/304，访问前检查素材记录和源文件；删除项目时预览随媒体目录移除。预览不改变原始素材、生成请求或导出输入。

节点选中、关联连线及拖动连接预览保留静态边框、线宽和颜色，不使用 SVG 阴影滤镜。单选节点的直接关联连线、或单选的连线，会增加沿源节点到目标节点移动的小光点。光点复用实际连接路径，使用浏览器原生 transform/opacity 动画，不逐帧更新 React 状态或 SVG 描边；缩放后仍保持约 6px 的屏幕尺寸。只对可见路径片段创建动画，同屏最多 24 个，更多关联线每 3.2 秒分组轮换；所有关联线仍持续高亮。多选、全选、隐藏连线、连线完全离屏、页面后台或系统减少动态效果时停止光点动画。路径注册和批量位置更新合并到每帧一次。

画布工具栏、节点列表和底部创作区移除背景模糊，节点采用轻量阴影。连接端口的磁吸更新合并到每帧一次，先读取坐标再更新样式；普通节点拖动和平移期间跳过磁吸扫描。隐藏连线会停止挂载其 SVG 路径，重新显示后恢复。

节点与连线复用未变更的属性、选项和事件入口；拖动只更新位置，避免重绘卡片正文。提示词使用节点及入边索引，自动设定连线仅在引用信息变化时重算。拖动与调整节点尺寸继续在操作结束时创建一次撤销记录并安排保存。

剧本设定器的水球 WebGL 持续动画最多绘制 24fps，像素倍率上限为 1.5，关闭抗锯齿并请求低功耗上下文。关闭、收起、离屏或页面进入后台时停止调度；系统启用减少动态效果时仅在尺寸、题材、封面或融合状态变化后重绘，静止时停止调度。融合与纹理状态在暂停期间保留。

## 历史验证记录

以下保留既有性能优化记录以说明当时的测量范围，不能用作 `9ba5a25` 全量测试已通过的证明。节点种类、视口、缓存、浏览器节流与构建模式都会影响结果。

独立浏览器模拟图包含 100、300、500 个混合节点，其中一半为长文本、四分之一为图片、四分之一为生成节点。在相同正常视角下，实际挂载节点分别由 100、300、500 个降为 6 个；全选仍覆盖完整图，富文本编辑器从 50、150、250 个降为 0 个。

该次开发构建中，全选操作的 React 渲染累计时间约从 129、249、407ms 降为 8、25、7ms。这是单次开发环境样本，不代表每帧耗时或生产环境性能保证。缩小视角中可见节点数量增加；当前保留内容预览，以更小的媒体预览和单选才创建的编辑器/播放器控制成本。

2026-10-11 首轮 GPU 优化检查使用真实项目中恢复的 54 节点画布，在相同正常视口下实际挂载 6 个节点，155 条连线中挂载 110 条；全选工具栏仍显示 54 个节点。全选后的持续动画由 155 个连线流光降为 0，画布背景模糊由 6 处降为 0，未选中视频播放器由 10 个降为 0。以下为首轮静态连线版本的样本，后续单选光点验证另见下文；全选仍保持无光点。

| 浏览器指标 | 优化前全选 | 优化后全选 | 优化后空闲 |
| --- | ---: | ---: | ---: |
| 2.5 秒内 Paint 事件 | 313 | 2 | 0 |
| 4 秒内主线程 TaskDuration | 约 275ms | 约 7.6ms | 约 6.9ms |
| 4 秒内 RecalcStyleDuration | 约 100ms | 0ms | 0ms |

这些是开发环境中的浏览器绘制/主线程样本，不是系统 GPU 占用百分比，也不是生产性能保证。长连线仍可能跨越视口，视频播放、复杂富文本和较多可见节点仍会带来渲染成本。

水球实测在同一 398×280 CSS 尺寸下，画布从 796×560 降为 597×420；离屏的 3 秒样本与减少动态效果静止时的 2.5 秒样本均为 0 次绘制，移除融合题材后只重绘一次并正常结束。此次验证浏览器的普通 rAF 回调也出现约 1 秒的间隔，正常动画帧率样本受到环境节流，不能直接与优化前的 68fps 比较；24fps 上限由独立调度回归测试验证。

500 节点测试覆盖全选、批量删除、撤销及屏幕外节点保存；独立浏览器模拟画布实际挂载 8 个节点，全选保留 500 个，删除后撤销恢复全部节点和连线，连接预览使用一条静态路径并可正常取消。此次相关回归覆盖节点尺寸与刷新稳定性、生成控件、提示词、媒体暂停与回退、视频封面并发缓存、水球融合/纹理生命周期及可见性调度。更多节点可分到项目内的多张画布。

内容与光点修订使用独立 500 节点模拟图，30% 缩放下挂载 48 个可见节点：16 个真实文字预览、32 个图片/视频封面，默认没有视频播放器。全选仍覆盖 500 个节点，编辑器、播放器及连线光点均为 0。一个节点关联 50 条线时同时运行 24 个光点并分组轮换；采样中光点与实际曲线的距离约 0.36 个屏幕像素。减少动态效果与模拟后台状态均停止光点，平移到关联线完全离屏后原生动画为 0，未发起项目数据写入。

修订后的普通单选连线在 2.5 秒样本中主线程 TaskDuration 约 2ms、样式重算 0ms；另一次完整的 2.5 秒跟踪中 Paint 和 Layout 均为 0，光点继续运行。密集 50 线的 4 秒样本包含分组轮换，TaskDuration 约 44ms、样式重算约 2.2ms、Paint 50 次；首次创建和轮换光点仍有绘制开销，不将动态效果描述为零成本。这些样本与前述真实项目场景不同，不直接比较百分比。46 项前端回归及生产构建通过，覆盖实际内容保留、预览尺寸切换、曲线裁剪与连续性、动画取消，以及原有编辑/保存/多选/媒体行为。
