# 前端组件与视觉规范

此规范以当前代码实现为准。技术栈保持 React 19、TypeScript、Vite 6、Mantine 9、React Flow 12、Tiptap 3 与 Lucide，改造不引入新依赖。

## 视觉系统

`web/src/styles/theme.css` 是全局颜色 token 的来源；`theme.ts` 配置 Mantine 字体、尺寸、组件默认值及语义色。工作区、画布和挂载到 body 的 Portal 使用相同 token。既有 workspace、canvas-chrome、select、creation 变量只是这些 token 的别名。

| 用途 | Token | 当前值 |
| --- | --- | --- |
| 画布背景 | `--fc-canvas` | `#101112` |
| 页面表面 | `--fc-surface` | `#17181a` |
| 弹层与面板 | `--fc-panel` | `#1c1e20` |
| 次级表面 / hover | `--fc-surface-muted` / `--fc-surface-hover` | `#25272a` / `#303338` |
| 主文字 / 次级文字 | `--fc-text` / `--fc-text-secondary` | `#f0f0ef` / `#c7c9cc` |
| 辅助文字 / 弱文字 | `--fc-text-muted` / `--fc-text-subtle` | `#a0a4aa` / `#858a92` |
| 常规边框 | `--fc-border` | `#36393e` |
| 主要操作 / 前景 | `--fc-primary` / `--fc-on-primary` | `#e8e9e6` / `#202225` |
| 焦点 | `--fc-focus` | `#acb3bf` |
| 开关开启轨道 / 滑块 | `--fc-switch-on` / `--fc-switch-thumb-on` | `#627f99` / `#d4e0e8` |
| 开关关闭滑块 | `--fc-switch-thumb-off` | `#a0a4aa` |
| 成功 / 警告 / 错误 | `--fc-success` / `--fc-warning` / `--fc-danger` | `#9ac9ae` / `#dbc295` / `#e6a099` |

中性石墨灰负责导航、编辑和制作界面；语义色只表达状态、错误和危险操作。项目封面、生成素材及题材水球保留自身色彩。浅色主按钮必须使用深色前景，禁止继承辅助文字色。显式危险菜单项保留组件的 `--menu-item-color`。

复选框统一由 `theme.ts` 的 Mantine `Checkbox` 配置管理，默认使用 `sm` 尺寸与圆角。选中和半选状态使用 `--fc-primary` 底色与 `--fc-on-primary` 图标色，浅色模式为石墨灰底与白色勾号，深色模式为浅灰底与深色勾号。页面不得单独覆盖复选框底色、边框或勾号颜色；布局和标签密度可按所在区域调整。禁用、错误与键盘焦点反馈保留 Mantine 行为，显式传入的语义色与图标色继续生效。

### 浅色与深色模式

项目页、普通工作区、画布和全屏剧本编辑器的右上角均使用共享 `ThemeToggle` 按钮。图标及提示文字表示将切换到的模式。首次进入默认深色；Mantine 自带的颜色模式管理器将选择保存到本地 `mantine-color-scheme-value`，刷新后恢复，并同步同源标签页。

点击切换时，支持 View Transition API 的浏览器以按钮中心为原点，用 550ms 圆形过渡切换主题。切到浅色时浅色页面向外展开，切回深色时浅色页面向按钮收回，露出下方深色页面。扩散半径覆盖最远的视口角落；所有按钮共享切换保护，避免重复触发。系统开启减少动态效果或浏览器不支持时直接切换。过渡只使用页面快照，不复制或重挂载工作区。

`theme.css` 根据根元素的 `data-mantine-color-scheme` 切换全局 token。浅色画布为 `#f5f6f7`，面板为白色，主文字为 `#20242a`，主要操作为 `#303943` 配白色前景；成功、警告和错误分别使用较深文字与浅色背景。既有画布、导演、模型及弹窗的局部变量在浅色模式下接入同一套 token；Portal 继承根主题。切换只改变显示和本地偏好，不重挂载编辑区或写入项目内容。媒体画面上的文字、比例标记和播放控制保留深色底与浅色文字，以保证画面上的对比度。

字体使用系统 SF Pro、苹方、微软雅黑与系统无衬线回退。项目标题约 30px；页面与面板标题 16–24px；基础控件 13px；辅助信息 11–12px。长剧本文字使用较宽行距，时间和数值使用等宽数字。外层容器与内层控件区分圆角；项目浏览保留留白，制作区保持紧凑。

反馈使用约 120–180ms 的颜色或透明度变化。焦点必须可见，禁用与加载状态必须保留；尊重 `prefers-reduced-motion`。避免重复光晕、大面积彩色渐变和持续装饰动画。

## 组件边界

业务基础交互使用实际 Mantine 组件，禁止新增手写原生控件或通过改名包装原生控件绕过约束。

| 交互 | 实现 |
| --- | --- |
| 常规动作 / 图标动作 | `Button` / `ActionIcon` |
| 自定义导航、可点击卡片和题材触发器 | `UnstyledButton` |
| 文本 / 多行文本 / 数字 | `TextInput` / `Textarea` / `NumberInput` |
| 单选卡片 / 复选 / 开关 | `Radio.Card` / `Checkbox` / `Switch` |
| 下拉 / 范围 / 进度 | `Select`、`Combobox` / `Slider` / `Progress` |
| 选项卡 / 表格 | `Tabs` / `Table` |
| 文件选择 | `FileButton`，保留原上传回调和输入引用 |
| 折叠区 | `WorkspaceDisclosure`，基于 `Accordion` |
| 菜单 / 内层选项 / 弹窗 / 手机导航 | `Menu` / `Popover` / `Modal` / `Drawer` |
| 视频、音频工具栏 | `StudioMediaPlayer`，基于 `ActionIcon`、`Slider`、`Menu`、`Tooltip` |

布局和内容仍可使用 `main`、`section`、`nav`、`div` 等语义 HTML。React Flow 保持画布引擎，Tiptap 保持可编辑文档，WebGL 保持题材预览，原生 `video` / `audio` 保持媒体解码和既有引用。这些底层元素不提供浏览器默认操作栏；基础交互由组件库提供。组件库最终生成 HTML 属于正常浏览器渲染。

`WorkspaceDisclosure` 使用 `keepMounted` 和 `display-none` 模式，关闭不会重挂载草稿、输入和媒体。`StudioMediaPlayer` 向外暴露原媒体元素引用，事件的 `currentTarget` 也仍是该元素；组件更新不会自行重载或暂停媒体。

## CSS 与弹层

`main.tsx` 必须先导入 Mantine 样式，再加载 App 及业务组件样式，最后导入全局 `theme.css`。否则同优先级的库样式可能覆盖导航和卡片布局。全局组件规则不得覆盖业务控件明确配置的前景色或危险色。

优先修改所属组件的现有规则，清理已经被替代的声明；避免继续追加同名覆盖层。Portal 的 token 放在 `:root`，不局限于 `.app-shell`。

剧本设定器 Modal 使用 300 层，已有下拉使用 400 层，媒体播放设置使用 450 层。设定器内部 Popover 保持在 Modal 内部，Escape 先关闭内层选项，再关闭设定器。Modal 内容高度自动，由 body 管理视口尺寸；中间内容可滚动，底部操作区固定可见。窄屏题材预览放在选择列表上方，避免预览被两条列表挤成零宽。

## 功能保护

迁移必须保留已有事件处理函数、API 地址与请求结构、禁用条件、状态默认值和保存时机。Select 和 NumberInput 的回调值与原生事件不同，显式适配后再调用既有逻辑。不要因样式迁移新增自动保存、生成、资产选用或画布写入。

保护画布坐标、视口与选择，保留 `nodrag` / `nowheel` 和 overlay 标记；编辑器菜单保持选区，不因焦点转移丢失内容。危险确认取消后的菜单状态与原行为一致。表单取消不得写入设置，媒体 ref 和事件对象保持原契约。

镜头提示词中的「镜头引用」在创作区内部展开，桌面端与提示词并排，窄屏上下排列。当前镜头范围固定，默认优先显示已引用设定；分类、搜索及「参考与用途」折叠仅改变界面。保存继续复用原绑定接口及即时保存时机，固定版本、独立参考图、用途和必需状态保持原契约。完整场次及设定使用范围管理仍复用同一编辑器。Escape 先收起引用，再关闭放大创作区，内层下拉优先处理 Escape。

画布连线默认使用中性灰 `#5c6066`，选中节点的关联线使用灰蓝 `#8daac0`，单独选中连线使用更亮的 `#bdd0df`；线宽分别为 1.5 / 2.4 / 2.8。保留现有基于 transform 的移动光点、视口裁剪、动画预算与减少动态效果设置。

浏览器验收只播放本地已有媒体并操作临时 UI 状态，不运行付费生成、提交配置或导出任务。导演入口可能创建项目剧本节点，应在隔离的只读校验环境中检查；校验结束移除临时文件。
