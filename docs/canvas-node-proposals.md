# 导演节点修改方案

## 使用方法

选中普通图片或视频生成节点，点击「添加到导演对话」。在导演输入区点击「调整节点配置」，填写希望调整的内容，选择已有文本模型后点击「生成修改方案」。这一按钮调用文本模型整理方案。

窗口展示完整原提示词、修改后提示词，以及改变的生成参数。检查后点击「确认创建草稿」，系统在来源画布新增一个独立生成节点，并按需新增固定参考图片节点。原节点、原连接和历史任务保留。确认仅保存画布草稿，图片或视频生成需要手动启动；使用画布撤销可撤回本次新增。

调整窗口的要求与导演输入草稿独立。生成、失败、取消及确认不会清空导演输入、引用或剧本草稿。未确认的方案保留在本次导演窗口内，关闭整个导演窗口后需重新生成方案。

## 首版范围

只允许修改完整提示词，以及当前模型和模式确实支持的参数：图片节点可调整比例；视频节点可调整比例、分辨率、时长、生成声音。图片分辨率和清晰度继续沿用原配置，避免两者的映射覆盖已审核的修改。目标模型、生成模式、固定素材 ID / 顺序 / 用途、候选数量与其他参数继续沿用原配置。模型模板未消费的字段、模式固定值和草稿模式固定值不开放修改。

首版支持普通图片和视频生成节点。视觉档案信息图节点与外部参考视频地址继续使用现有专用流程；要调整带参考视频的普通节点，请先将视频导入项目。快照和方案均为文字配置，不代表文本模型已经看过参考素材画面。

## 校验与恢复

可编辑的导演文字不作为修改授权来源。画布另行捕获结构化来源，绑定项目、画布版本、源节点及其输入、真实生成预览、画风和镜头版本。保存来源画布后重新读取项目版本，避免自动保存使快照立即过期。

方案接口只生成提示词与允许的参数补丁。确认前再次核对本地未保存编辑、服务端画布、模型、参考素材文件及镜头绑定。来源变化时拒绝旧方案，保留已有内容，并提示重新添加节点快照。当前版本采用保守校验：移动节点、其他画布编辑或项目版本变化也可能要求重新读取。

每份方案绑定固定的新节点 ID。重复确认或保存失败后重试会复用已经创建的草稿，避免重复新增。参考图片通过固定素材 ID 连接，不自动换成上游节点后续生成的新结果；同一来源的多个视角可由必要的独立图片节点承载。

## 开发接口

- `POST /api/projects/:id/canvases/:canvasId/node-proposals`：提交文本模型、调整要求和结构化来源，返回 `before` / `after`、修改说明与确认校验指纹。模型输出通过严格字段和参数能力检查。
- `POST /api/projects/:id/canvases/:canvasId/node-proposals/validate`：确认前只读校验环境指纹，不调用模型。
- 确认写入复用原有画布保存和版本冲突机制；两个方案接口均不创建生成任务、镜头、素材或剧本文档草稿。
