# 从第一次打开到导出成片

[← 使用指南](README.md) · [安装与启动](../README.md#快速开始)

用一个小范围走通流程：先准备一场剧本和少量镜头，再扩展到整部作品。已有图片、视频和音频时，可以直接跳到[剪辑与导出](#5-剪辑与导出)。

## 先认识几个对象

| 对象 | 用来做什么 | 一个例子 |
| --- | --- | --- |
| 项目 | 保存一部作品的资料与素材 | 一支短片 |
| 剧本与场次 | 组织故事和要拍的内容 | 第 1 场：车站重逢 |
| 分镜 | 把场次拆成具体镜头 | 远景交代环境、近景表现反应 |
| 画布 | 组织生成输入与候选 | 文本 → 图片 → 视频 |
| 成片 | 决定最终采用的顺序与片段 | 选片或独立剪辑时间线 |

## 1. 启动并配置模型

按首页的[快速开始](../README.md#快速开始)启动应用，再按[模型配置指南](model-setup.md)添加服务。剧本与分镜规划使用文本模型；图片、视频任务使用对应类型的模型。

**完成标志：** 项目可以打开，创作页面能选择已启用的模型。

## 2. 准备剧本

创建项目，填写创作概述与画幅。然后选择一种起点：

| 起点 | 怎么做 |
| --- | --- |
| 只有创意 | 打开剧本对话，先讨论方向，再按阶段生成并确认保存 |
| 有完整原稿 | 上传原稿，讨论内容，再选择需要整理或修订的阶段 |
| 已有文字内容 | 在剧本中编辑并保存，再选择需要制作的场次 |

**完成标志：** 项目文档中存在已保存的正文与场次。模型回复和待确认草稿尚未等同于正式保存。

详细操作：[阶段创作](model-intent-workflow.md) · [原稿上传](script-source-context.md)。

## 3. 规划分镜并加入画布

选择本次场次，点击 **加入画布**。未规划的场次点击 **开始规划**，检查镜头、时长与提示词，再确认加入。

**完成标志：** 画布中出现本次镜头与生成节点。已有有效分镜可直接复用，多张画布与重新设计方案的区别见[多画布指南](project-canvases.md)。

需要改镜头或顺序时，使用[分镜管理](shot-management.md)。

## 4. 准备并选择素材

在画布中配置提示词、参考图与模型，显式提交图片或视频生成；也可以导入现有素材。查看候选，审查人物、动作及镜头衔接，再选择要用的内容。

**完成标志：** 素材库中有可用的图片或视频，镜头已有候选。生成完成本身不代表已经选入成片。

参考图怎么选见[多视角参考](multi-angle-reference-workflow.md)。页面刷新或服务重启后，先[找回原任务](generation-restart-recovery.md)，再决定后续操作。

## 5. 剪辑与导出

打开 **成片工作台**，按目标选择入口：

| 我想做什么 | 选择 |
| --- | --- |
| 按分镜比较候选、逐镜选片和检查接镜 | **按分镜选片** |
| 自由组合素材、多段取用、加入字幕 | **基础剪辑** |

需要对白或旁白时，先[制作配音](tts-standard-voice-workflow.md)，再在当前成片中设置位置和取段。检查预览后保存并导出，等待结果出现后下载 MP4。

**完成标志：** 下载区显示本次成片，而非修改前的旧版本。完整步骤见[基础剪辑指南](basic-final-cut.md)。

## 哪些动作会调用模型？

| 动作 | 是否调用 |
| --- | --- |
| 打开页面、查看已保存分镜、导入素材 | 不会因此调用生成模型 |
| 剧本对话、原稿分析、分镜规划、整理提示词 | 使用已配置的文本模型，可能计费 |
| 确认加入画布时补齐或更新视觉设定 | 需要整理时会调用文本模型，可能计费 |
| 生成图片、视频或配音 | 使用所选服务，可能计费 |
| 本地剪辑与 FFmpeg 导出 | 本地处理，不调用生成模型 |

先检查输入与范围，再提交生成。一次创作任务可能包含多次模型请求；费用以实际使用的服务为准。
