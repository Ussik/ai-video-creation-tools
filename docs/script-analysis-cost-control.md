# 剧本候选稿分析与用量控制

候选稿修订以完整当前文稿为输入，修订后再分析新稿。修订前不再生成没有被修订请求使用的目录。

候选稿可以复用已通过质量核对、模型和配置一致的旧稿目录页。程序检查原文范围、逐字证据和版本绑定；变化范围及关联章节重新分析。每个新稿仍重新进行全剧综合、全文质量核对和独立阶段设定复核，原始上传文件与显式保存确认保留。

全剧时间线、伏笔和不确定事项按目录事实的预计输出容量分组，每组最多 32 段。每个任务仍读取完整原文与目录。已有旧布局 checkpoint 按旧布局继续，避免部署后丢失完成结果。跨组合法引用由程序校验、精确去重并合并引用；内容或证据不合法仍停止处理。

## 用量预算

同一个上传版本、同一个阶段范围和集数共享累计预算。候选稿版本变化、自动修订、连接中断、进程恢复和点击“继续”都不会清零；其他阶段独立计数。替换或删除上传文件清理对应私有账本，确认保存修订稿不会重置账本。

环境变量（正整数）：

| 变量 | 默认值 | 含义 |
| --- | --- | --- |
| `VIDEO_STUDIO_SCRIPT_ANALYSIS_MAX_REQUESTS` | 120 | 累计模型生成请求上限，含修订、格式修正、网络重试、文稿分析和阶段复核 |
| `VIDEO_STUDIO_SCRIPT_ANALYSIS_MAX_TOKENS` | 3000000 | 发出下次请求前核算的累计 token 预算 |

达到预算时保留草稿、分析页和复核 checkpoint，停止发出后续生成请求。核对执行记录后可提高环境变量并继续原任务。调整处理方案不会重置 token 预算。

请求发出前持久化输入估算和输出预留；供应商上报实际用量后逐字段替换对应估算。推理 token 是输出 token 的子集，不重复相加。无用量上报或结果不确定的请求保留估算；缺少输出上限及配置预留时使用 4096 token 的初始预留，已观察到的输出超出预留时上调。因此预算属于发出请求前的控制，并非供应商账单的精确上限。

后台响应的轮询和取消单独计传输次数，不消耗模型生成请求数；最终响应按 ID 对账。执行记录显示实际内部进度和累计用量；修订项计数仅代表补丁完成，不代表文稿分析与独立复核完成。

## 修订收敛

同一处理方案最多累计四轮修订后未通过复核；“继续”保留累计轮次，传输中断不增加轮次。到限后保留候选稿，要求调整方案或明确重新委托 AI 决定。完整质量门槛与显式保存确认不受轮次限制影响。

## 验证限制

回归测试使用模拟模型及本地模拟 HTTP 服务，不请求真实供应商。历史未记录的模型用量不能从新账本追溯补齐；实际节省比例应从后续执行记录测量。
