# 剧本候选稿分析与用量控制

> 实现核对：2026-10-22，代码基线 `9ba5a25`。本页预算适用于有上传原稿的候选修订、修订后来源分析与阶段独立复核链路；上传后台分析和首次阶段生成各有自己的执行限制，不能将本页数值理解为项目总额度。

候选稿修订以完整当前文稿为输入，修订后再分析新稿。修订前不再生成没有被修订请求使用的目录。

候选稿可以复用已通过质量核对、模型和配置一致的旧稿目录页。基线取自当前有效稿的已保存分析或兼容的 `source-proposal-base`；程序检查原文范围、逐字证据和版本绑定，变化范围及关联章节重新分析。每份内容变化的新稿仍重新进行全剧综合、全文质量核对和独立阶段设定复核；同内容、同配置且已通过的私有分析可直接复用。原始上传文件与显式保存确认保留，具体复用与完整回退条件见[原文资料策略](script-source-context.md)。

全剧时间线、伏笔和不确定事项按目录事实的预计输出容量分组：累计预估超过 12,000 字符或已有 32 段时开始下一组，单章保持完整。每个任务仍读取完整原文与目录。新布局使用 `source-story-parts-v4`；匹配的旧 v3 checkpoint 按原每 12 章布局继续，避免丢失完成结果。跨组合法引用由程序校验、精确去重并合并引用；内容或证据不合法仍停止处理。人物批次另按最多 12 个目录姓名规划，后续批次可保守使用原文证据包，最终质量核对仍读取全文。

## 用量预算

同一个不可变上传版本下，以 `[stage, scope, episode_number]` 为范围共享累计预算。候选稿版本变化、自动修订、连接中断、进程恢复和点击“继续”都不会清零；其他范围独立计数。替换、重新上传或删除上传文件清理对应私有账本，确认保存修订稿不会重置账本。没有上传原稿时不创建这份候选分析私有账本。

环境变量（正整数）：

| 变量 | 默认值 | 含义 |
| --- | --- | --- |
| `VIDEO_STUDIO_SCRIPT_ANALYSIS_MAX_REQUESTS` | 120 | 该范围内累计模型请求上限，含候选修订、格式修正、网络重试、修订后文稿分析和阶段复核 |
| `VIDEO_STUDIO_SCRIPT_ANALYSIS_MAX_TOKENS` | 3000000 | 发出下次请求前核算的累计 token 预算 |

下次模型请求会超过任一预算时，在发出前停止，保留草稿、分析页和复核 checkpoint。核对执行记录后可提高服务端环境变量，并在新配置生效后继续原任务。调整处理方案或重新委托 AI 可开启新的修订轮次额度，但不会重置请求数和 token 账本。

请求发出前持久化输入估算和输出预留；供应商上报实际用量后逐字段替换对应估算。推理 token 是输出 token 的子集，不重复相加。无用量上报或结果不确定的请求保留估算；缺少输出上限及配置预留时使用 4096 token 的初始预留，已观察到的输出超出预留时上调。因此预算属于发出请求前的控制，并非供应商账单的精确上限。

后台响应的轮询和取消单独计传输次数，不消耗模型生成请求数；最终响应按 ID 对账。执行记录显示实际内部进度和累计用量；修订项计数仅代表补丁完成，不代表文稿分析与独立复核完成。

## 修订收敛

同一处理方案最多累计四轮修订后未通过复核；“继续”保留累计轮次，传输中断不增加轮次。到限后保留候选稿，要求调整方案或明确重新委托 AI 决定。完整质量门槛与显式保存确认不受轮次限制影响。

## 实现位置与验证限制

账本范围与配置：`backend/src/modules/script/script-proposal-budget.ts`；请求预留、实际用量替换与 response ID 对账：`backend/src/infrastructure/providers/text-request-usage.ts`；修订与复核调用范围：`backend/src/app.ts` 的 `resumeScriptDraft` 和 `reviewDirectorDraft`；四轮规则：`backend/src/modules/script/script-draft-repair-rounds.ts`。

账本保存在 `script_step_checkpoints` 的 `source-proposal-usage` 命名空间，绑定原始上传版本；普通生成检查点清理保留它。损坏或互相矛盾的累计计数会拒绝恢复，不能自动归零绕过预算。上下文窗口预检与单步时间限制分别见[容量预检](text-model-context-capacity.md)和[任务恢复](script-task-recovery.md)。

现有回归测试使用模拟模型及本地模拟 HTTP 服务，不请求真实供应商；本次文档更新未重新运行真实模型或成本实验。历史未记录的模型用量不能从新账本追溯补齐；实际节省比例应从后续执行记录测量。
