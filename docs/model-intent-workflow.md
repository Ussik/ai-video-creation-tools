# 对话意图与分集创作

自由对话不再用固定措辞或关键词路由。后端先使用当前选中的文本模型独立判断讨论、澄清、生成、修订或采用已有正文，再把已确认的要求交给写作调用。集数和单集时长同样由模型结合上下文理解；制作片段时长与单集时长分别处理。

点击明确的阶段生成按钮时，阶段和集数来自结构化参数，协调调用只整理已确认的对话资料，不能改变按钮选择。格式解析、模型可用性、参数范围、文档类型、目标集数和项目归属仍由程序校验。识别失败不回退到文字规则，也不自动保存。

模型任务分别使用独立请求：协调调用读取项目状态和近期对话；写作调用读取相关已保存文档及协调后的创作要求，不携带整段备选方案；接镜检查读取当前制作范围、人物场景资料和镜头状态。它们使用同一个选中的模型，但不共享混杂的任务提示。

分集流程：创作或采用正文 → 草稿预览 → 确认保存 → 分集目录/编辑器 → 选择本集场次加入画布或制作分镜。采用已有消息会逐字保留正文，只让模型整理场次。待确认草稿不会被新的创作请求覆盖。

镜头站位、武器、姿态、面具和道具连续性由显式触发的模型文字检查判断，不再靠关键词。基础素材/时长检查保持本地执行。语义检查结果按镜头与剧本资料快照缓存，变化后显示过期；普通刷新不会再次付费调用模型。检查不代表实际视频画面已经通过审核。

模型目录的输出类型以提供商能力元数据或用户明确选择为准，不根据模型名称猜测。题材封面和颜色使用现有选项的明确映射；未知题材使用中性外观，不承担语义分类。

成本：自由对话和阶段创作通常包含一次协调调用与一次回复/写作调用；仅需澄清时只执行协调调用。点击采用正文只进行一次场次整理。未自动调用图片或视频模型。
