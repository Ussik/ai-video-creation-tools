# 剧本分镜的运镜与接镜优化

日期：2026-11-09。用户确认问题位于「剧本生成分镜」，并授权直接优化。

## 现在的行为

生成时先明确每场固定空间锚点、人物调度、摄影机轴线和戏剧推进，再逐镜给出职责、起始构图、运动触发、路径/速度、结束构图与动机。每镜另有明确切点、交接状态和切镜理由。允许固定镜头、反打、插入镜、明确省略和换场，不强迫每镜移动或每个转场共用构图。

分镜阶段沿用分镜主/辅助技能绑定；运动文字补充当前项目或全局的视频提示词绑定。实际规则、文件、版本和绑定理由分别返回预览。显式选择基础规则时，两组外部规则都不加载，不更改原有绑定或模型。

生成后先验证场次范围、镜头身份、时长、声音来源及编译长度，再对整组设计做文字语义复核。复核看到全部镜头的摄影设计、首帧、视频说明、起止与接镜、直接相邻关系和原始来源。最新正式正文与明确设定优先于滞后的场次摘要和旧镜头。固定或有理由的省略不是机械缺陷。

有执行错误时最多进行一次内容修订，再重新复核；剩余错误直接返回具体镜头与修复建议。节奏或动机的非阻断风险在预览中呈现供创作者判断。手工编辑镜头、时长或镜头顺序后，旧复核状态失效。预览继续由用户确认保存，保存/提交沿用原字段，无数据库迁移。

专业设计编译到现有文本字段，用完整起止标记替换先前编译区块，避免重新规划叠加旧运镜。可编辑的时长、起止与接镜不再冻结成视频正文的重复快照；制作时统一附上当前保存的边界，并说明当前值优先于旧正文状态。

图片转视频分析使用同项目、同方案的直接前后镜，排除删除、被替代和其他方案。邻镜只能提供动作、空间、视线和摄影衔接参考，不能为本镜提供台词证据。邻镜变化使缓存或进行中的结果失效。有邻镜时会进行承接分析。旧自动视频正文和旧空提示词回退格式通过精确匹配继续识别，手动追加或改写保持保护。

取消规划会将 AbortSignal 传递到规则读取、生成、复核和修订，防止断开请求后继续启动后续调用。

完整构建仍有 Vite 大包提示；相关 React 集成测试有既有 act 提示，最终用例均通过。没有将这次定向回归描述为全仓库测试。

未调用真实文本/图像/视频服务，未自动保存或改写用户现有分镜，未提交或部署。文字复核不能证明真实视频的艺术效果。常规新规划增加一次整组文本复核；发现错误时还会增加修订和复查，因此调用量与等待时间会增加。
