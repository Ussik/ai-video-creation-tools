# 创作链路的语义契约改造

日期：2026-11-09

## 问题与边界

分镜中的对白曾在图片到视频的承接阶段被丢弃。已检查的重试请求在提交视频供应商前就没有台词，有限句式的正则提取无法覆盖真实创作表达。此次将具有语义决定权的词表、句式与关键词猜测改为模型判断、结构化结果及受限工具调用。

格式解析、ID/权限、原文证据、来源版本、长度预算、模型参数、持久化和并发保护继续由程序确定性处理。模型输出不合法时纠正或报错；不会通过程序猜造台词、改写镜头时长或把未知声音当成无声。

## 已落地的契约

| 范围 | 模型职责 | 程序职责 |
| --- | --- | --- |
| 分镜与图片到视频承接 | 输出 `motion_prompt` 和 `audio_plan`；结合原分镜动作、最新图片设计、已有声音及连接的局部文本 | 校验 schema、原文摘录、镜头归属和来源签名；将声音计划渲染进最终视频提示词 |
| 提示词整理 | 独立语义复核事实、人物、参考身份、视角、授权修改和台词；最多一次修正 | 验证来源证据及结构，记录输入和候选签名，拒绝未通过的结果 |
| 视觉参考视角 | 按对象和镜头输出 `reference_view` 枚举或 null | 保存选择，自动同步和显式刷新时保留；遵守手选和锁定 |
| Skills 补充资料 | 使用 `read_skill_reference` / `submit_skill_references`；导演支持 `read_creation_skill_reference` | 只暴露已安装、锁定版本的文档目录；验证文件 ID、版本、内容哈希和总预算 |
| 原始剧本的问答范围 | 输出原文版本、章节 ID、字面检索词及范围决策 | 校验章节和版本，读取精确原文；无效或失败时保留全文 |
| 文档类型与角色上下文 | 判断资料类型、角色身份和是否需要完整原文 | 保存证据和依赖；不按少量关键词删除历史上下文 |
| 分镜时长 | 根据动作和对白分配秒数，错误时重新规划 | 验证每场总秒数，失败时终止；不静默按比例缩放 |

Skills 的固定主技能、人工选择和已保存任务继续有效。必需依赖由明确清单及结构化阶段/对象信息确定；可选资料由模型读取选择，不再以创作正文的关键词作为加载依据。补充资料缓存仅在调用方提供模型配置复用键时启用。

## 音频数据与旧节点

`audio_plan` 包含版本、说话人、原文台词、发声方式、对白/旁白模式、原文摘录、音效、音乐和明确无声标记。新分镜输出必须提供该结构，数据库中旧数据的 null 表示尚未分析。

旧的自动视频节点可使用“分析并恢复动作与台词”。直接生成遇到待恢复节点时，先完成分析并展示恢复结果，之后再生成。打开页面及预览不会触发模型调用。已缓存且来源未变的分析会复用。

手改内容和活动任务受到保护；恢复保留位置、候选结果、时长及分辨率。图片、镜头状态或局部输入改变后，旧分析不再自动视为有效。并发返回必须仍对应原图和当前画布，才允许保存。

修改镜头叙事或视频提示词时，未显式同时提供声音计划则清除旧计划，防止台词已改而继续复用旧音频。声音计划也覆盖未自定义图片和通过素材关联镜头的路径。
