# 已安装技能的推荐配置与使用位置

配置日期：2026-10-31。已通过本机 Studio 正式接口保存为**全局默认**。当前 5 个故事项目均继承全局配置，没有项目覆盖；以后沿用全局默认的项目也会使用这套组合。

## 日常推荐组合（已设置）

| 创作环节 | 界面使用位置 | 主技能 | 辅助技能 | 主要用途 |
| --- | --- | --- | --- | --- |
| 剧本创作 | 剧本导演、剧本/阶段草稿生成 | `short-drama-write` | 无 | 创作场次、动作和对白，按因果、钩子、退出状态及真实表演时长自检 |
| 视觉设定 | 画布左侧「设定 → 设定工具 → 批量整理草稿」、分镜后的「参考设定整理」、导演人物/场景/道具模式 | `short-drama-assets` | 无 | 整理人物、地点、道具及变体，检查设定与跨镜连续性 |
| 图片提示词 | 图片生成节点、设定信息图节点的「整理提示词」 | `short-drama-image-prompts` | 无 | 整理静态构图、参考图职责、人物外观与可见状态 |
| 分镜规划 | 剧本/故事板「加入画布 → 开始规划」中的「本次分镜技能」 | `short-drama-storyboard` | 无 | 拆分镜头、安排景别机位、动作/对白落点、起止状态与接镜 |
| 视频提示词 | 视频生成节点的「整理提示词」 | `short-drama-video-prompts` | 无 | 整理动作变化、表演、运镜、对白和时长，匹配目标模型能力 |

五个主技能本身都有与阶段相符的检查要求。当前默认不增加辅助，以保持任务职责和输出目标一致。

此次重新评估后，已从五阶段默认中移除 `short-drama-review`，并从剧本默认中移除 `short-drama-develop`。这替代了早先把审查作为通用辅助的推荐。审查技能保留视觉设定适用范围，但不参与日常生成默认。

依据是现装正文的任务边界：`short-drama-review` 明确“只写审查问题、结论和修订要求”“审查与修改分开执行”；`short-drama-develop` 明确不写场景动作与台词，并要求需要质量结论时把 review 作为后续单独请求。将这些指令常驻写作、提示词整理等生成任务，会增加职责和输出目标冲突。当前配置依据职责相容性选择，未通过同模型成片对比证明质量提升。

## 按具体任务选用的技能

以下技能保持启用。选择器默认显示「模型自动选择」；发送任务后由模型判断，执行活动或结果中显示实际选用的技能及理由。日常默认仅作为模型的参考，也可手动更换。

模型结合本次要求、阶段、上下文及可用技能说明进行选择，不需要固定句式。手动选择和浏览器记住的选择优先，包括明确不使用外部技能。

| 技能 | 什么时候使用 | 在哪里选择 |
| --- | --- | --- |
| `short-drama-develop` | 探索故事方向、人物冲突引擎、系列大纲与分集地图 | 剧本导演中做上述开发任务时临时选为主技能；写正式场次时恢复 `short-drama-write` |
| `short-drama-review` | 已有内容，需要问题、证据、影响与修订要求的独立审查 | 明确要求审稿的对话中临时选为主技能；不用于要求返回改写正文的「整理提示词」操作 |
| `short-drama-novel-analyze` | 有原著输入，需要提取人物关系、剧情因果、改编边界时；不承担正式剧本写作 | 剧本导演的剧本创作技能选择器，原著分析任务中选用 |
| `novel-outline` | 小说改编、分集大纲、每集钩子和资产规模规划 | 剧本创作技能选择器 |
| `novel-script` | 明确希望使用节拍化动作/对白、固定节奏预算的改编方案 | 剧本创作技能选择器；通常作为专项方案的主技能 |
| `novel-characters` | 从较长小说提取角色表、人物画像、形象及音色方向 | 视觉设定整理的技能选择器 |
| `novel-art` | 制作空场景环境资产、场景光照变体、独立道具资产 | 视觉设定或图片「整理提示词」的技能选择器 |
| `novel-storyboard` | 明确需要 H3/Seedance 的生成段、段内切镜、关键帧与台词落点规划 | 分镜规划或视频「整理提示词」的技能选择器 |

这些备选具有更固定的制作约定，不适合全部叠加到通用默认：`novel-art` 包含英文提示词、空景与白底道具规则；`novel-script` 有固定节拍和对白预算；`novel-storyboard` 有默认不超过 15 秒的生成段、2–5 秒切镜与 H3 语法。按目标任务选择，能减少对普通镜头和其他模型的干扰。

Shuohao 系列的部分核心参考文件目前不会被应用自动加载，且其附带脚本不会执行。因此这里推荐的是已经导入的文本方法，不代表完整原生工具流程已接入。

## 查看和切换配置

在「技能中心 → 默认技能」查看这五个阶段的全局组合。进入故事项目后也可切换「当前项目」，单独保存项目默认。

图片/视频「整理提示词」会在当前浏览器记住手动选择。如果选择器显示「已记住的选择」或「手动选择」，点击「恢复模型自动选择」即可重新按任务选择；此操作不修改项目或全局默认。保存默认仍通过「设为项目默认／设为全局默认」完成。

自动选技现已使用模型 Function Calling，替换原先的关键词规则。导演在原工具循环中选技；独立整理／规划操作会在创作前增加一次模型选技。模型必须选取已启用且适配环节的技能；无有效选择时会提示失败，不静默退回关键词匹配。提示词整理仍须返回改写正文，不应被只输出报告的审查技能替代。详见 [当前选技机制](../task-skill-assignment.md)。

技能在上述文本创作、规划和提示词整理步骤使用。节点里已经保存的提示词不会因修改默认而重写；需要整理时，再主动执行对应操作并审阅应用结果。
