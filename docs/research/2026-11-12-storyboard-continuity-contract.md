# 分镜起止、声场与草稿复核

本轮沿用已有分镜导演和视频运动两个 skills 的职责，补齐规划结果在独立视频制作中的传递。没有重新生成或修改已有视频。

## 两个规划入口

- 正式场次：继续按剧本顺序规划、编译并复核全部相邻镜头。
- 片段规划：使用同一导演 schema、两类技能和导演复核；`groups` 仅表示片段内部连续时空，不创建正式剧本场次。明确的换场或时间变化使用不同组。
- 两者对有证据的 error 最多做一次完整语义修订，再复核。warning 保留给创作者判断。
- 先按行动、对白与反应确定镜头职责，再确定镜数和镜长；无统一字速或动作数配额，不为技术额度机械拆镜。

## 持久化

镜头新增可空 `continuity_plan`，版本为 1，保存场景空间/声场与本镜摄影/交接设计。旧记录保留 null，不推断历史设计。读取 malformed JSON 也返回 null。

`status: accepted | edited` 区分规划接受的快照和已手改的镜头。手改后的当前 `image_prompt/start_state/end_state/video_prompt/cut_note` 是当前设计；旧快照不能反向覆盖它。

通用镜头编辑、分镜管理和导演镜头修改都会标记语义改动；重排与复制按前后真实邻接关系退役受影响方案，纯编号变化、标题和同值修改不会误标。视觉文字调整保留已确认的音频计划作为复核基准，不能通过清空计划绕过原台词保护；声音需要独立明确修订。

共同声音写入 `audio_plan.scene_sound`，单镜的 `ambience_change` 表达相对变化。场景音乐默认 `timeline`，配乐意图交后期；明确接受本镜带配乐时才使用 `source`。全程静音优先于共同声场。旧无共同声音字段的音频计划保持原行为。

## 检查重点

- 核对完整首帧正文与追加约束，避免正文已呈现终态、起点却要求动作尚未发生。
- 核对邻镜同一道具的归属、双手、动作阶段，以及换手或时间省略依据。
- 核对同场共同声音、单镜进入/退出与配乐政策，允许明确留白及合理的声源距离变化。
- 所有语义问题提供当前设计证据，不能按“左/右”等关键词机械报错，也不能声称看过或听过未提供的媒体。

## 草稿复查

两个规划预览均有显式“复查当前草稿”。修改后旧报告标记 edited；复查仅返回绑定当前内容签名的报告，不重写、不保存镜头，也不启动媒体生成。正式场次和片段分别使用 `/script/storyboard/review`、`/storyboard/clip/review`。

## 目标视频模型

规划可选 `target_video_model_id`，与用于文字规划的 `model_id` 独立。后端验证模型/提供商可用性，按真实配置传入目标方言和参考预算；模型配置变化使相应预览失效。未指定时使用通用制作规则，不声称具有某模型的参考或声音能力。

文字复核和共同声场约束只能降低设计矛盾，不能证明实际独立视频接得上，也不能保证模型每次产生相同环境音。真实切点画面、完整对白、口型与声音仍需成片预览验证。

## 生成前交接与最终提示词

正常分镜视频基稿和图转视频均带入结构化声音执行约束。新规划的画面运动与声音各写入对应字段；保留旧作者正文，明确声音以确认的音频区块为准，`timeline` 不要求本镜重新生成配乐。旧自动基稿仍可恢复，手改视频草稿受到保护。

图转视频分析同时检查首帧完整正文、当前起止状态和相邻交接。明确矛盾返回逐字依据和修改建议，不用追加一句限制掩盖正文矛盾。前镜选用素材与接受的取段会参与快照，分析期间变化则拒绝套用旧结果。

入口：画布选中视频生成节点 →「查看生成信息」→「生成前接镜核对」。主动调用所选文本模型，可选择同时提供前镜实际尾帧和本镜参考图；关闭图片核对时只审文字。默认保留原台词、说话者、画内/画外方式与顺序。图片节点及待交接节点也可在分析前明确允许改词；许可变化会使旧结果失效。

最终核对绑定实际提示词、目标模型、模式、时长、声音开关、参考和相邻素材版本。已确认台词缺失或生成声音关闭时会报告问题。存在当前版本的明确错误时，修改后重新核对或显式保留当前设计继续；未主动核对不会产生后台文本模型调用。核对报告与确认状态仅保留在当前页面。

## 基础剪辑中的实际接镜

入口：成片工作台 → 基础剪辑 → 入片顺序旁「接镜复核」。展示两侧实际出入点帧，可试调候选出点/入点，播放切点前后各约1.2秒的当前混音。预演沿用原声增益/淡变、独立配音、配乐位置和字幕，不因裁剪预演窗口额外制造淡变。

查看、播放和调整候选值均不改原素材。确认检查完整台词、口型和动作后，才能应用候选切点到当前草稿；仍须保存剪辑。人工复核标记仅保留本次页面，素材、顺序、取段或混音改变后需复查。同一素材重复使用按片段实例区分。
