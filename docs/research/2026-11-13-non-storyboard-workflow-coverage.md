The generic budget admits only real provider dispatches, reserves unknown output conservatively and carries old reservations across recovery. Generation requests, transport polls, token use and active duration have separate limits. Allowances freeze at creation, scale by bounded manuscript/unit size, and permit at most three grants. Automatic reconnect and service reconstruction do not grant more work. Admission must precede checkpoint cloning; all newly budgeted creative callers follow that boundary.

`model-workflow-budget` includes simultaneous-owner regression coverage: a queued execution cannot clone the checkpoint before the current owner finishes, and both real dispatch usage and validated units survive. `isolated-model-graph` enables inherited callbacks plus LangChain/LangSmith environment flags and asserts zero export requests while local source-review stage results remain observable.

Regression changes explicitly wait for an already completed late provider response to reach its exact request journal before recovery. That response can be consumed without a second dispatch. Unknown dispatches remain guarded by the existing provider recovery barrier; these tests do not authorize resending them.
