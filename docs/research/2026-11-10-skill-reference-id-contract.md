# 补充资料选择的目录 ID 契约

## 本地失败证据

截图对应任务 `01082545-2213-41f7-98a9-cffe3836ea05`，北京时间 2026-11-10 17:45:37–17:45:56，用时 18.8 秒。持久记录显示两轮均为工具响应，仅调用 `submit_skill_references`，最终诊断为 `invalid_selection`、`fields: [reference_ids]`、`stop_reason: no_progress`。同项目当日还有三次相同诊断。

按请求及当前绑定，任务处于全剧场景设计环节，使用 `short-drama-develop`。主规则和必需资料约 56,755 字符（未含外层包装），21 份可选资料含标题合计约 33,136 字符；不重复且来自目录的选择不会超预算。原始提交参数没有持久保存，因此无法进一步断定实际错误是字段类型、重复 ID、相对路径还是其他目录外 ID。

## 契约缺口与修复

旧工具 Schema 只要求字符串，没有提供本次目录 ID 枚举。实际 ID 是 `skill_id:完整资料路径`，主规则正文中的相对链接、已加载必需资料链接均不能直接作为可选资料 ID。旧诊断还将重复、目录外选择和预算问题统一显示为 `reference_ids`。

`backend/src/modules/skills/model-skill-selection.ts` 现在根据本次锁定目录生成读取、提交及结构化返回的 ID 枚举。提示明确复制目录的完整 `id`，不重复提交已加载资料，并使用当次目录中的真实 ID 展示格式。空目录的选择数组上限为零。

本地校验继续独立检查结构、目录归属、重复和预算；模型不能通过文本返回或工具提交绕过它。纠错工具结果仅提供安全的错误类别、字段路径、本次合法 ID、剩余预算和包含标题的资料字符数。最终错误保存细分 `issues`，不复制模型提交的错误 ID、理由、正文或 JSON 解析器片段。保留一次无进展纠正、读取轮数上限、取消及资料版本冲突的原有行为。
