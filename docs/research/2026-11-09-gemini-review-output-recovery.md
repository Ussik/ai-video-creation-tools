# Gemini 剧本审读输出超限恢复验收

日期：2026-11-09。范围：剧本生成后的自动审读、显式文档审读及其证据定位和问题归组。本次只使用隔离临时数据库与模拟上游，没有调用真实付费模型、调整用户模型配置或部署服务。

## 问题与实现

本地 Gemini 配置使用第三方 OpenAI 兼容 Responses 网关；请求模板没有显式 `max_output_tokens`。`output_reserve_tokens` 是容量估算预留，无法提高真实上游输出额度。本地未保留可对应本次反馈的失败记录，实际故障是否由网关默认额度或思考用量耗尽引发仍未知。公开网关页面可以访问，但 `/docs` 与 `/openapi.json` 返回前端页面，未找到可核验的参数映射或额度文档，因此没有按模型名称猜测上限或注入思考参数。

- 自动审读保留正常整体验证及三个核查维度；维度再次超限后分页返回完整问题，每页仍读取完整输入。
- 共用分页器保存已闭合并通过 schema 和业务校验的条目。完整 `complete:true` 与聚合校验全部通过后才能完成；截断回复只能贡献合法条目，不能贡献完成标记。
- 分页断点绑定完整请求、结构及条目上限。重复或无进展时单页由最多八项逐步缩为一项，仍无进展则明确停止并保留成果；达到契约总上限时报错，不丢弃问题。
- 手动文档审读遇到原生工具输出截断后重建报告，重新取得完整读取凭证并检查完整有效稿、其他成果、场次、决定、要求与规则。全部完成后经既有入口提交一次，正文不变。
- 手动恢复在每次请求及提交前校验来源、目标版本与审读上下文；已提交断点还核对实际报告 ID，避免已成功提交但总结超限后的重复报告。
- 证据定位与问题归组超限后同样保存分页，维持逐字引文、全索引覆盖及历史决定唯一性校验。
- 提供商适配层在明确超限后最多等一秒收集可选用量尾帧，保留先前正文及累计用量；取消仍立即生效。截断工具参数从不返回为可执行调用。
- 仅输出超限的模型调用详情显示实际请求上限、估算预留、结束原因及可用用量，区分正文、思考和工具参数超限。普通创作进度仍保持简洁。

## 独立复核与修正

独立代理复核后修正了四处边界：整体截断中已识别问题在分维度空结果后仍保留；null 定位结果不写成完成断点；手动审读完整上下文和已加载规则进入版本身份；预先取消的分页继续不会清除旧进度。补查未发现剩余必须修复的无限重试、截断工具执行或错误提交路径。

## 验证

后端及前端 TypeScript 检查通过；架构/UI 控件检查 `npm run check` 与 `git diff --check` 通过。先前集成用例仍按旧的四次请求断言，而当前既有逐文档生成会处理八份缺失成果；将断言改为目标文档数量后回归通过，没有为此更改运行逻辑。
