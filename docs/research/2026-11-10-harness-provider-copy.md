# DeepSeek Harness 提供商配置复刻

本次按本机 DeepSeek Harness 实际界面重做提供商配置。此前实现只改变模型编辑弹窗，没有完成提供商主页面与模型目录的交互。

## 参考界面与实现

只读打开 DeepSeek Harness 设置 → 模型 → 编辑 gemini → 自定义设置 → 模型选项，核对后取消退出，没有保存 Harness 配置或请求其模型目录。

- 提供商使用纵向卡片列表，卡片右侧编辑、删除，底部添加模型提供商。
- 编辑在卡片内展开；首项 API 密钥，默认折叠自定义设置。
- 自定义设置顺序：显示名称、API 地址、API 协议、模型目录。
- 协议包含 OpenAI Chat Completions、OpenAI Responses、Anthropic Messages。
- 模型目录行包含排序手柄、模型 ID、显示名称、选项箭头、删除；支持拖动或键盘上下调整顺序。
- 文本模型选项为上下文窗口、最大输出 token 数、输入类型、推理等级开关及档位/API 参数值；默认六行 off/low/medium/high/xhigh/max。
- 容量支持 K/M，1M、128K 为输入提示，不自动写入额度。项目另外保留默认档位，作为实际请求的推理档位。
- 卡片统一取消/保存，编辑、添加、删除、排序都先留在草稿；取消不保存。获取目录使用草稿连接，不保存连接或立即导入。
- 图片、视频、费用、结构化输出、特殊自定义接口仍可在高级设置中配置。项目默认模型保留在独立折叠区域。

这是在现有 Mantine/工作台外壳中的相同配置层级和交互；没有复制 Harness 的账号登录、内置官方模型和“恢复默认模型”等本项目没有对应数据的功能。

## 参数与兼容

提供商默认协议与模型 sort_order 持久化，新增文本模型继承提供商协议。切换协议时，标准且继承的文本模型跟随，显式覆盖或自定义模板保持原协议；旧提供商未设默认协议时只推导显示，用户未更改协议就不会写回。

整卡新增/更新使用事务，任何校验或保存失败均不留下部分连接/模型改动。未修改的旧模板、停用未配置模型和媒体设置原样保留。生成任务及导演任务运行时禁止修改所用配置。

标准 text_api 生成实际协议请求。输出额度进入对应 max_completion_tokens/max_tokens/max_output_tokens 字段；上下文窗口参与完整请求容量预检。新推理映射使用同一数据来源，主界面与高级表单不会分别写入两套生效冲突的参数。off 在 Chat/Responses 使用 effort=none，Anthropic 使用 thinking=disabled；是否接受所配档位仍取决于上游模型。

新增 Anthropic 原生 Messages 适配覆盖普通/流式响应、工具调用、图片、结构化输出、用量和截断诊断。它要求显式最大输出，不注入 8K 默认；工具参数未完整闭合时不执行。原生工具历史完整保留并进行容量预检，暂不套用 OpenAI 历史压缩器。

运行时校验改为必须传入实际协议，补齐导演与创作等入口，防止标准表单在发请求前因缺协议被误判。
